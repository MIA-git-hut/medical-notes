# 解表药古籍来源试点

本页只说明本轮已核对的防风、麻黄两条古籍事实来源，不属于药物条目，也不参与中药条目统计。现有中药学目录中的其他解表药没有因此获得“已核对”状态。

这里的 `reviewed` 仅表示维护者已将卡片文字与固定版本的数字来源逐项核对，不表示医学专家审核，不构成现代诊疗或用药建议。

## 防风

已核对事实限于《神农本草经》原条的味、气、“无毒”、别名“铜芸”及“生川泽”。“无毒”为古籍用语，不等于现代安全结论。

## 麻黄

已核对事实限于《神农本草经》原条的味、气、“无毒”、历史主治文字、别名“龙沙”及“生山谷”。这些内容不是现代用药建议；本试点没有补写剂量。

## 使用边界

学习卡只问可从上述原文直接作答的事实。现代性味归经、适应证、禁忌、相互作用与剂量均需另有可靠现代来源和审核流程，不能从本页外推。
