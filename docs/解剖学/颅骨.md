# 颅骨

成人颅骨共 **23 块**（不含 3 对听小骨），分为**脑颅**与**面颅**两部分。

## 脑颅（8 块）

围成颅腔，容纳并保护脑。

| 骨 | 数量 | 位置 |
| --- | --- | --- |
| 额骨 | 1 | 前部 |
| 顶骨 | 2 | 顶部两侧 |
| 枕骨 | 1 | 后下部 |
| 颞骨 | 2 | 两侧 |
| 蝶骨 | 1 | 颅底中央 |
| 筛骨 | 1 | 两眶之间 |

> [!tip]
> 脑颅口诀：「一额两顶一枕，两颞一蝶一筛」

## 面颅（15 块）

构成面部支架，形成眶、鼻腔和口腔。

| 骨 | 数量 |
| --- | --- |
| 下颌骨 | 1 |
| 犁骨 | 1 |
| 舌骨 | 1 |
| 上颌骨 | 2 |
| 腭骨 | 2 |
| 颧骨 | 2 |
| 鼻骨 | 2 |
| 泪骨 | 2 |
| 下鼻甲 | 2 |

> [!warning]
> 舌骨是颅骨中**唯一不与其它骨形成关节**的骨，以韧带和肌悬于颈前。

## 翼点（pterion）

颞窝内，额、顶、颞、蝶四骨汇合处，形似「H」形缝。

> [!warning]
> 翼点处骨质薄弱，内面有**脑膜中动脉前支**通过，此处骨折易伤及该动脉，引起硬膜外血肿——考试常考点。
