# 内环境与稳态

## 内环境的概念

细胞外液是细胞直接生活的液体环境，即**内环境**。

| 部位 | 构成 |
| --- | --- |
| 血浆 | 血细胞周围的液体 |
| 组织液 | 组织细胞之间的液体 |
| 淋巴 | 淋巴管内流动的液体 |

> [!tip]
> 内环境 = 细胞外液 = 血浆 + 组织液 + 淋巴

## 稳态

内环境的理化性质（温度、pH、渗透压、各种化学成分）保持**相对恒定**的状态，称为稳态。

维持稳态的基本途径：

1. **神经调节**——反应最快
2. **体液调节**——作用范围广、持续时间长
3. **自身调节**——局部、稳定、幅度小

> [!warning]
> 稳态是**动态平衡**，不是固定不变；机体各器官系统协调活动的结果。
