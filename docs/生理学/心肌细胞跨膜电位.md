# 心肌细胞的跨膜电位

## 两类心肌细胞

| 特征 | 快反应细胞（心室肌、心房肌） | 慢反应细胞（窦房结、房室结） |
| --- | --- | --- |
| 静息电位 | 约 -90 mV | 无稳定静息电位 |
| 0 期去极化 | 快，由 Na⁺ 内流 | 慢，由 Ca²⁺ 内流 |
| 4 期 | 稳定 | 自动去极化（自律性） |

## 心室肌细胞的 5 个时相

| 时相 | 名称 | 主要离子流 |
| --- | --- | --- |
| 0 期 | 快速去极化 | Na⁺ 内流（快钠通道） |
| 1 期 | 快速复极初期 | K⁺ 外流 |
| 2 期 | 平台期 | Ca²⁺ 内流与 K⁺ 外流平衡 |
| 3 期 | 快速复极末期 | K⁺ 外流 |
| 4 期 | 静息期 | 泵入泵出恢复离子浓度 |

> [!tip]
> **平台期**是心肌细胞区别于骨骼肌、神经细胞的重要特征，是心肌细胞有效不应期长、不产生强直收缩的根本原因。

## 窦房结 P 细胞的自动去极化

4 期存在自动去极化，由以下机制引起：

1. **K⁺ 外流逐渐衰减**（最主要）
2. 内向电流（Na⁺、Ca²⁺ 背景电流）逐渐增强

> [!warning]
> 窦房结 P 细胞 4 期自动去极化速度最快，故窦房结是心脏的正常起搏点。
