# 使用指南

这个网站只需要你**写 Markdown 笔记**，其他一切（导航、搜索、部署）都自动完成。

## 日常使用流程

1. 打开 **Obsidian**，进入 `D:\medical-notes\docs` 这个库（Vault）
2. 左侧按科目进入对应文件夹（如 `生理学`、`公众号`），点「新建笔记」写笔记
3. 写完后 **Ctrl+S 保存** —— 网站侧边栏会自动出现这篇笔记，**不需要改任何配置**
4. 双击桌面上的 **「一键发布网站.bat」**，看到「发布成功」提示
5. 等 1-2 分钟，刷新 https://medical-notes-iota.vercel.app 就能看到更新

## 手动发布（备用）

在 `D:\medical-notes` 文件夹空白处右键 →「在终端中打开」，依次输入：

```
git add -A
git commit -m "更新笔记"
git push origin main
```

## 常用 Markdown 写法

```md
# 一级标题
## 二级标题

**加粗**、*斜体*、`代码/药名`

## 表格
| 结构 | 数量 | 位置 |
| ---- | ---- | ---- |
| 额骨 | 1 | 前部 |

## 提示框
> [!tip]
> 重点记忆的内容

> [!warning]
> 容易混淆、考试常考的内容
```

## 添加图片

把图片文件放进 `docs\public` 文件夹，然后在笔记中引用：

```md
![图片说明](/图片名.png)
```

## 常见问题

- **发布后网站没变**：等 1-2 分钟再刷新（浏览器缓存就按 Ctrl+F5）
- **网站打不开**：确认用的是正确的网址，域名没变
- **发布窗口出现红字**：截图发给 Claude 帮忙看
