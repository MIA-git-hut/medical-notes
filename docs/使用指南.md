# 使用指南

这个网站只需要你**写 Markdown 笔记**，其他一切（导航、搜索、部署）都自动完成。

## 日常使用流程

1. 打开 `D:\medical-notes\docs` 文件夹，按科目进入对应文件夹（如 `解剖学`）
2. 新建一个 `.md` 文件，例如 `心脏.md`，用任何文本编辑器（推荐 [VS Code](https://code.visualstudio.com/) 或 Typora）写笔记
3. 在 `docs\.vitepress\config.mjs` 的 `sidebar` 里加一行链接
4. 打开终端输入 `npm run dev`，浏览器访问 `http://localhost:5173` 预览
5. 用 `git push` 推送后，Vercel 自动更新线上网站

## 常用 Markdown 写法

```md
# 一级标题
## 二级标题

**加粗**、*斜体*、`代码/药名`

## 表格
| 结构 | 数量 | 位置 |
| ---- | ---- | ---- |
| 额骨 | 1 | 前部 |

## 提示框
> [!tip]
> 重点记忆的内容

> [!warning]
> 容易混淆、考试常考的内容
```

## 添加图片

把图片文件放进 `docs\public` 文件夹，然后在笔记中引用：

```md
![图片说明](/图片名.png)
```

## 常用命令

| 命令 | 作用 |
| ---- | ---- |
| `npm run dev` | 本地预览 |
| `npm run build` | 构建检查 |
| `git push` | 发布更新 |
