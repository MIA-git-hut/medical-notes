# 使用指南

这个网站只需要你**写 Markdown 笔记**，其他一切（导航、搜索、部署）都自动完成。

## 日常使用流程

1. 打开 **Obsidian**，进入 `D:\medical-notes\docs` 这个库（Vault）
2. 左侧按科目进入对应文件夹（如 `生理学`、`公众号`），点「新建笔记」写笔记
3. 写完后 **Ctrl+S 保存** —— 网站侧边栏会自动出现这篇笔记，**不需要改任何配置**
4. 双击桌面上的 **「一键发布网站.bat」**，看到「发布成功」提示
5. 等 1-2 分钟，刷新 https://medical-notes-iota.vercel.app 就能看到更新

## 手动发布（备用）

在 `D:\medical-notes` 文件夹空白处右键 →「在终端中打开」，依次输入：

```
git add -A
git commit -m "更新笔记"
git push origin main
```

## 常用 Markdown 写法

```md
# 一级标题
## 二级标题

**加粗**、*斜体*、`代码/药名`

## 表格
| 结构 | 数量 | 位置 |
| ---- | ---- | ---- |
| 额骨 | 1 | 前部 |

## 提示框
> [!tip]
> 重点记忆的内容

> [!warning]
> 容易混淆、考试常考的内容
```

## 添加图片

把图片文件放进 `docs\public` 文件夹，然后在笔记中引用：

```md
![图片说明](/图片名.png)
```

## 常见问题

- **发布后网站没变**：等 1-2 分钟再刷新（浏览器缓存就按 Ctrl+F5）
- **网站打不开**：确认用的是正确的网址，域名没变
- **发布窗口出现红字**：截图发给 Claude 帮忙看

## 炫酷功能（已开启）

以下功能已经装好，写笔记时直接用即可：

### 流程图 / 时序图（Mermaid）

````mermaid
flowchart TD
  A[出现症状] --> B{影像检查}
  B -->|阳性| C[确诊]
  B -->|阴性| D[继续观察]
````

### 公式（KaTeX）

行内公式写 `$...$`，例如 $Na^+$；独立公式写 `$$...$$`：

$$
\Delta V = \frac{RT}{zF} \ln \frac{[X]_o}{[X]_i}
$$

### 代码块图标（group-icons）

用 `::: code-group` 包裹即可，自动显示文件类型图标：

````md
::: code-group

```sh [安装]
npm install
```

```sh [部署]
npm run build
```

:::
````

### 图片点击放大

笔记里的图片点击后会自动放大查看，再点一次关闭。

### 评论区（giscus）

每篇笔记底部自动显示评论区，评论保存在 GitHub Discussions 里。
