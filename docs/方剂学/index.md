# 方剂学知识库

> [!tip] 方从法出，法随证立；君臣佐使，各有法度。

「溯本医源」的方剂学知识库：按教材章节整理常用方剂的歌诀、组成、用法、功用主治、方解与经典出处，并与[中药学](/中药学/)药卡、[四大经典](/四大经典/)原文互相链接。**只做知识整理与检索，不做诊疗建议。**

搜索方式：导航栏搜索按钮、快捷键 `Ctrl+K`。

## 教材依据

整理框架依据全国中医药行业高等教育「十五五」规划教材《方剂学》的章节体系：**总论 + 各论**，每方一页。组成、用法、主治以《伤寒论》《金匮要略》宋本原方为底本，功效与方解参教材通行之说；**无原方依据者只列方目，不立页、不补造**。
