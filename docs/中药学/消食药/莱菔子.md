# 莱菔子

> [!info] 速记
> 消食除胀、降气化痰为要

## 性味归经
- 性味：辛、甘，平
- 归经：肺、脾、胃经

## 功效
- 消食除胀
- 降气化痰

## 主治
- 饮食停滞，脘腹胀痛，大便秘结
- 痰壅喘咳

## 用法用量
- 煎服，6～10g；生用吐风痰，炒用消食下气化痰

## 禁忌
- 气虚无食积、痰滞者慎用；不宜与人参同用
