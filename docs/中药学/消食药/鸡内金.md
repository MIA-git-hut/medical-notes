# 鸡内金

> [!info] 速记
> 健胃消食、涩精止遗为要

## 性味归经
- 性味：甘，平
- 归经：脾、胃、小肠、膀胱经

## 功效
- 健胃消食
- 涩精止遗
- 通淋化石

## 主治
- 食积不消，呕吐泻痢，小儿疳积
- 遗精遗尿
- 石淋涩痛，胆结石

## 用法用量
- 煎服，3～10g；研末服，每次1.5～3g

## 禁忌
- 脾虚无积者慎用
