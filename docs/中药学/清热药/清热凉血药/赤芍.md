# 赤芍

> [!info] 速记
> 清热凉血、散瘀止痛为要

## 性味归经
- 性味：苦，微寒
- 归经：肝经

## 功效
- 清热凉血
- 散瘀止痛

## 主治
- 温毒发斑、血热吐衄
- 目赤肿痛
- 肝郁胁痛
- 经闭痛经、癥瘕腹痛
- 跌打损伤
- 痈肿疮疡

## 用法用量
- 煎服，6～12g

## 禁忌
- 血寒经闭者不宜；反藜芦
