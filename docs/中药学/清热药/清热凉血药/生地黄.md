# 生地黄

> [!info] 速记
> 清热凉血、养阴生津为要

## 性味归经
- 性味：甘、苦，寒
- 归经：心、肝、肾经

## 功效
- 清热凉血
- 养阴生津

## 主治
- 热入营血、温毒发斑
- 血热吐衄
- 热病伤阴、舌绛烦渴
- 阴虚内热、骨蒸劳热
- 津伤口渴、内热消渴

## 用法用量
- 煎服，10～15g

## 禁忌
- 脾虚湿滞、腹满便溏者不宜
