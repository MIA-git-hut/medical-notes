# 玄参

> [!info] 速记
> 清热凉血、泻火解毒为要

## 性味归经
- 性味：甘、苦、咸，微寒
- 归经：肺、胃、肾经

## 功效
- 清热凉血
- 泻火解毒
- 滋阴

## 主治
- 温邪入营、温毒发斑
- 热病伤阴
- 咽喉肿痛、痈肿疮毒
- 瘰疬痰核
- 劳嗽咳血

## 用法用量
- 煎服，9～15g

## 禁忌
- 脾胃虚寒、食少便溏者不宜；反藜芦
