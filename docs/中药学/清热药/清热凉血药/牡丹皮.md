# 牡丹皮

> [!info] 速记
> 清热凉血、活血化瘀为要

## 性味归经
- 性味：苦、辛，微寒
- 归经：心、肝、肾经

## 功效
- 清热凉血
- 活血化瘀

## 主治
- 温毒发斑、血热吐衄
- 温病后期阴虚发热
- 血滞经闭、痛经
- 跌打损伤
- 痈肿疮毒

## 用法用量
- 煎服，6～12g

## 禁忌
- 血虚有寒、月经过多及孕妇不宜
