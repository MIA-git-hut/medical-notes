# 胡黄连

> [!info] 速记
> 退虚热、除疳热为要

## 性味归经
- 性味：苦，寒
- 归经：肝、胃、大肠经

## 功效
- 退虚热
- 除疳热
- 清湿热

## 主治
- 骨蒸潮热
- 小儿疳热
- 湿热泻痢、痔疮肿痛

## 用法用量
- 煎服，3～10g

## 禁忌
- 脾胃虚寒者慎用
