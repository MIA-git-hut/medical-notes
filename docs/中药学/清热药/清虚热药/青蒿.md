# 青蒿

> [!info] 速记
> 清透虚热、凉血除蒸为要

## 性味归经
- 性味：苦、辛，寒
- 归经：肝、胆经

## 功效
- 清透虚热
- 凉血除蒸
- 解暑
- 截疟

## 主治
- 温邪伤阴、夜热早凉
- 阴虚发热、骨蒸劳热
- 暑热外感
- 疟疾寒热

## 用法用量
- 煎服，6～12g，后下

## 禁忌
- 脾胃虚弱、肠滑泄泻者忌用
