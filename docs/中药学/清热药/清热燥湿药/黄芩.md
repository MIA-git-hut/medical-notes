# 黄芩

> [!info] 速记
> 清热燥湿、泻火解毒为要

## 性味归经
- 性味：苦，寒
- 归经：肺、胆、脾、胃、大肠、小肠经

## 功效
- 清热燥湿
- 泻火解毒
- 止血
- 安胎

## 主治
- 湿温、暑湿
- 肺热咳嗽
- 血热吐衄
- 胎动不安
- 疮痈肿毒

## 用法用量
- 煎服，3～10g

## 禁忌
- 脾胃虚寒者不宜
