# 黄连

> [!info] 速记
> 清热燥湿、泻火解毒为要

## 性味归经
- 性味：苦，寒
- 归经：心、脾、胃、肝、胆、大肠经

## 功效
- 清热燥湿
- 泻火解毒

## 主治
- 湿热痞满、泻痢
- 心火亢盛、心烦不寐
- 胃火牙痛
- 痈肿疮毒

## 用法用量
- 煎服，2～5g

## 禁忌
- 脾胃虚寒者忌用；苦燥伤阴，阴虚津伤者慎用
