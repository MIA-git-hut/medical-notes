# 栀子

> [!info] 速记
> 泻火除烦、清热利湿为要

## 性味归经
- 性味：苦，寒
- 归经：心、肺、三焦经

## 功效
- 泻火除烦
- 清热利湿
- 凉血解毒
- 外用消肿止痛

## 主治
- 热病心烦
- 湿热黄疸
- 血淋涩痛
- 血热吐衄
- 疮疡肿毒

## 用法用量
- 煎服，5～10g

## 禁忌
- 脾虚便溏者不宜
