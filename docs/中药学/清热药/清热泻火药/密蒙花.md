# 密蒙花

> [!info] 速记
> 清热泻火、养肝明目为要

## 性味归经
- 性味：甘，微寒
- 归经：肝、胆经

## 功效
- 清热泻火
- 养肝明目
- 退翳

## 主治
- 目赤肿痛、多泪、目生翳膜
- 肝虚目暗

## 用法用量
- 煎服，3～9g

## 禁忌
- 无明显禁忌
