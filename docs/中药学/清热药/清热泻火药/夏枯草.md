# 夏枯草

> [!info] 速记
> 清热泻火、明目为要

## 性味归经
- 性味：辛、苦，寒
- 归经：肝、胆经

## 功效
- 清热泻火
- 明目
- 散结消肿

## 主治
- 肝火上炎目赤肿痛、头痛眩晕
- 瘰疬瘿瘤

## 用法用量
- 煎服，9～15g

## 禁忌
- 脾胃虚弱者慎用
