# 竹叶

> [!info] 速记
> 清热泻火、除烦为要

## 性味归经
- 性味：甘、辛、淡，寒
- 归经：心、胃、小肠经

## 功效
- 清热泻火
- 除烦
- 生津
- 利尿

## 主治
- 热病烦渴
- 口疮尿赤
- 热淋

## 用法用量
- 煎服，6～15g

## 禁忌
- 阴虚火旺、骨蒸潮热者不宜
