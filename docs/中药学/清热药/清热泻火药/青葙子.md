# 青葙子

> [!info] 速记
> 清热泻火、明目退翳为要

## 性味归经
- 性味：苦，微寒
- 归经：肝经

## 功效
- 清热泻火
- 明目退翳

## 主治
- 肝热目赤、目生翳膜
- 视物昏花

## 用法用量
- 煎服，9～15g

## 禁忌
- 青光眼患者禁用
