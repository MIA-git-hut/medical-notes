# 芦根

> [!info] 速记
> 清热泻火、生津止渴为要

## 性味归经
- 性味：甘，寒
- 归经：肺、胃经

## 功效
- 清热泻火
- 生津止渴
- 除烦
- 止呕
- 利尿

## 主治
- 热病烦渴
- 胃热呕哕
- 肺热咳嗽、肺痈吐脓
- 热淋涩痛

## 用法用量
- 煎服，15～30g

## 禁忌
- 脾胃虚寒者慎用
