# 决明子

> [!info] 速记
> 清肝明目、润肠通便为要

## 性味归经
- 性味：甘、苦、咸，微寒
- 归经：肝、大肠经

## 功效
- 清肝明目
- 润肠通便

## 主治
- 目赤肿痛、羞明多泪
- 目暗不明
- 肠燥便秘

## 用法用量
- 煎服，9～15g，打碎用

## 禁忌
- 气虚便溏者不宜
