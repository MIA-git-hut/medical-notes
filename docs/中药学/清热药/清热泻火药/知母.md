# 知母

> [!info] 速记
> 清热泻火、滋阴润燥为要

## 性味归经
- 性味：苦、甘，寒
- 归经：肺、胃、肾经

## 功效
- 清热泻火
- 滋阴润燥

## 主治
- 热病烦渴
- 肺热燥咳
- 骨蒸潮热
- 内热消渴

## 用法用量
- 煎服，6～12g

## 禁忌
- 脾虚便溏者不宜
