# 石膏

> [!info] 速记
> 生用：清热泻火，除烦止渴、煅用：敛疮生肌，收湿止血为要

## 性味归经
- 性味：甘、辛，大寒
- 归经：肺、胃经

## 功效
- 生用：清热泻火，除烦止渴
- 煅用：敛疮生肌，收湿止血

## 主治
- 温热病气分实热证（壮热烦渴）
- 肺热喘咳
- 胃火牙痛、头痛
- 疮疡溃后不敛（煅用）

## 用法用量
- 煎服，15～60g，先煎；内服宜生用

## 禁忌
- 脾胃虚寒及阴虚内热者忌用
