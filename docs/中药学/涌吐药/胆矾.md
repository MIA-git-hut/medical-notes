# 胆矾

> [!info] 速记
> 涌吐痰涎、解毒收湿为要

## 性味归经
- 性味：酸、涩、辛，寒；有毒
- 归经：肝、胆经

## 功效
- 涌吐痰涎
- 解毒收湿
- 祛腐蚀疮

## 主治
- 风痰壅塞，喉痹
- 癫痫
- 口疮，牙疳
- 疮疡不敛，胬肉

## 用法用量
- 温水化服，0.3～0.6g；外用适量

## 禁忌
- 有毒，体虚者忌用；过量可致中毒
