# 瓜蒂

> [!info] 速记
> 涌吐痰食、祛湿退黄为要

## 性味归经
- 性味：苦，寒；有毒
- 归经：胃经

## 功效
- 涌吐痰食
- 祛湿退黄

## 主治
- 痰涎宿食，壅塞上脘，胸中痞硬，烦懊不眠
- 湿热黄疸

## 用法用量
- 煎服，3～6g；入丸散服，0.3～1g；外用适量

## 禁忌
- 有毒，体虚、失血及上部无实邪者忌用
