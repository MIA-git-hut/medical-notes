# 地龙

> [!info] 速记
> 清热定惊、通络为要

## 性味归经
- 性味：咸，寒
- 归经：肝、脾、膀胱经

## 功效
- 清热定惊
- 通络
- 平喘
- 利尿

## 主治
- 高热神昏，惊痫抽搐
- 关节痹痛，肢体麻木，半身不遂
- 肺热喘咳
- 小便不利，尿闭不通

## 用法用量
- 煎服，5～10g；研末吞服，每次1～2g

## 禁忌
- 脾胃虚寒者慎用；孕妇慎用
