# 珍珠

> [!info] 速记
> 安神定惊、明目消翳为要

## 性味归经
- 性味：甘、咸，寒
- 归经：心、肝经

## 功效
- 安神定惊
- 明目消翳
- 解毒生肌
- 润肤祛斑

## 主治
- 惊悸失眠，惊风癫痫
- 目赤翳障
- 疮疡不敛
- 皮肤色斑

## 用法用量
- 研末冲服或入丸散，0.1～0.3g；外用适量

## 禁忌
- 孕妇慎用
