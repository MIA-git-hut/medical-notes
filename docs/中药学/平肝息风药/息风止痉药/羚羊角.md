# 羚羊角

> [!info] 速记
> 平肝息风、清肝明目为要

## 性味归经
- 性味：咸，寒
- 归经：肝、心经

## 功效
- 平肝息风
- 清肝明目
- 散血解毒

## 主治
- 肝风内动，惊痫抽搐
- 肝阳上亢，头晕目眩
- 肝火炽盛，头痛目赤
- 温热病壮热神昏，热毒发斑

## 用法用量
- 煎服，1～3g，单煎2小时以上；磨汁或研粉服，每次0.3～0.6g

## 禁忌
- 脾虚慢惊者忌用
