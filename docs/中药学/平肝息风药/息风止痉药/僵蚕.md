# 僵蚕

> [!info] 速记
> 息风止痉、祛风止痛为要

## 性味归经
- 性味：咸、辛，平
- 归经：肝、肺、胃经

## 功效
- 息风止痉
- 祛风止痛
- 化痰散结

## 主治
- 惊痫抽搐，中风口歪，破伤风
- 风热头痛，目赤咽痛
- 风疹瘙痒
- 痰核瘰疬

## 用法用量
- 煎服，5～10g；研末吞服，每次1～1.5g

## 禁忌
- 血虚生风者慎用
