# 牛黄

> [!info] 速记
> 凉肝息风、清心豁痰为要

## 性味归经
- 性味：甘，凉
- 归经：心、肝经

## 功效
- 凉肝息风
- 清心豁痰
- 开窍醒神
- 清热解毒

## 主治
- 热病神昏，中风痰迷
- 惊痫抽搐
- 咽喉肿痛，口舌生疮，痈肿疔疮

## 用法用量
- 入丸散，0.15～0.35g；外用适量

## 禁忌
- 非实热证不宜用；孕妇慎用
