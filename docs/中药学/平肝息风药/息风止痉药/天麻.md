# 天麻

> [!info] 速记
> 息风止痉、平抑肝阳为要

## 性味归经
- 性味：甘，平
- 归经：肝经

## 功效
- 息风止痉
- 平抑肝阳
- 祛风通络

## 主治
- 肝风内动，惊痫抽搐
- 眩晕头痛
- 肢体麻木，手足不遂，风湿痹痛

## 用法用量
- 煎服，3～10g；研末冲服，每次1～1.5g

## 禁忌
- 无明显禁忌
