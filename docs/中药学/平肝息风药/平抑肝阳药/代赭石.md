# 代赭石

> [!info] 速记
> 平肝潜阳、重镇降逆为要

## 性味归经
- 性味：苦，寒
- 归经：肝、心经

## 功效
- 平肝潜阳
- 重镇降逆
- 凉血止血

## 主治
- 肝阳上亢，头晕目眩
- 呕吐、呃逆、噫气
- 气逆喘息
- 血热吐血、衄血、崩漏

## 用法用量
- 煎服，9～30g，打碎先煎

## 禁忌
- 孕妇慎用；虚寒证忌用
