# 牡蛎

> [!info] 速记
> 重镇安神、潜阳补阴为要

## 性味归经
- 性味：咸，微寒
- 归经：肝、胆、肾经

## 功效
- 重镇安神
- 潜阳补阴
- 软坚散结
- 收敛固涩

## 主治
- 心神不安，惊悸失眠
- 肝阳上亢，头晕目眩
- 痰核瘰疬，癥瘕积聚
- 滑脱诸证（自汗盗汗、遗精、崩带）

## 用法用量
- 煎服，9～30g，先煎；收敛固涩宜煅用

## 禁忌
- 虚而有寒者忌用
