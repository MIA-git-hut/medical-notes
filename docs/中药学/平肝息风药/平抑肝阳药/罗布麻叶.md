# 罗布麻叶

> [!info] 速记
> 平肝安神、清热利水为要

## 性味归经
- 性味：甘、苦，凉
- 归经：肝经

## 功效
- 平肝安神
- 清热利水

## 主治
- 肝阳眩晕，心悸失眠
- 水肿尿少

## 用法用量
- 煎服或开水泡服，6～12g

## 禁忌
- 不宜过量久服
