# 刺蒺藜

> [!info] 速记
> 平肝解郁、活血祛风为要

## 性味归经
- 性味：辛、苦，微温；有小毒
- 归经：肝经

## 功效
- 平肝解郁
- 活血祛风
- 明目
- 止痒

## 主治
- 肝阳眩晕，头痛
- 胸胁胀痛，乳闭乳痈
- 目赤翳障
- 风疹瘙痒

## 用法用量
- 煎服，6～10g

## 禁忌
- 有小毒，孕妇慎用；血虚气弱及阴虚火旺者慎用
