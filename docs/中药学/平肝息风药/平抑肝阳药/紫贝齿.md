# 紫贝齿

> [!info] 速记
> 平肝潜阳、镇惊安神为要

## 性味归经
- 性味：咸，平
- 归经：肝、心经

## 功效
- 平肝潜阳
- 镇惊安神
- 清肝明目

## 主治
- 肝阳眩晕
- 惊悸失眠
- 目赤翳障

## 用法用量
- 煎服，10～15g，打碎先煎

## 禁忌
- 脾胃虚寒者慎用
