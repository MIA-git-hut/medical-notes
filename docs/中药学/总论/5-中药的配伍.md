## 第二节 药物的七情

| 七情 | 含义 | 举例 |
| --- | --- | --- |
| 单行 | 单味药独用 | 独参汤、清金散（待核对） |
| 相须 | 性能功效相类似的药物配合，增强原有疗效 | 石膏配知母（待整理） |
| 相使 | 一药为主，另一药为辅以提高主药疗效 | 黄芪配茯苓（待整理） |
| 相畏 | 一药的毒副作用被另一药抑制 | 半夏畏生姜（待整理） |
| 相杀 | 一药能减轻或消除另一药的毒副作用 | 生姜杀半夏（待整理） |
| 相恶 | 两药合用，一药使另一药原有功效降低甚至丧失 | 人参恶莱菔子（待整理） |
| 相反 | 两药合用能产生或增强毒性或副作用 | 十八反（待整理） |
