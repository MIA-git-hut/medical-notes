# 中药学知识库

> [!tip] 四气五味，归经升降；君臣佐使，各有所长。

「溯本医源」的中药学知识库：按教材章节整理每一味中药的性味归经、功效主治、用法禁忌与现代药理。**只做知识整理与检索，不做诊疗建议**；内容尽力标注出处、可溯源。

搜索方式：导航栏搜索按钮、快捷键 `Ctrl+K`，或在[首页](/)检索框直接输入药名。

## 教材依据

整理框架依据全国中医药行业高等教育「十五五」规划教材《中药学》（第 6 版／十二版，钟赣生、杨柏灿主编，中国中医药出版社，2026 年秋季启用）：**总论 7 章 + 各论 21 章 + 附录**，全书收药 568 味（掌握 133、熟悉 98、了解 114、参考 98、附药 125）。
