# 芒硝

> [!info] 速记
> 泻下通便、润燥软坚为要

## 性味归经
- 性味：咸、苦，寒
- 归经：胃、大肠经

## 功效
- 泻下通便
- 润燥软坚
- 清火消肿

## 主治
- 实热积滞，大便燥结
- 咽痛口疮，目赤肿痛，痈疮肿痛

## 用法用量
- 冲入药汁或开水溶化后服，6～12g；外用适量

## 禁忌
- 孕妇及哺乳期妇女忌用；不宜与三棱同用
