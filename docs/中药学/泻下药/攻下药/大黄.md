# 大黄

> [!info] 速记
> 泻下攻积、清热泻火为要

## 性味归经
- 性味：苦，寒
- 归经：脾、胃、大肠、肝、心包经

## 功效
- 泻下攻积
- 清热泻火
- 凉血解毒
- 逐瘀通经
- 利湿退黄

## 主治
- 积滞便秘
- 血热吐衄，目赤咽肿
- 热毒疮疡，烧烫伤
- 瘀血证
- 湿热痢疾，黄疸，淋证

## 用法用量
- 煎服，3～15g，后下或开水泡服；泻下攻积宜生用，活血化瘀宜酒制，止血宜炒炭

## 禁忌
- 脾胃虚弱者慎用；妇女妊娠期、月经期、哺乳期应慎用
