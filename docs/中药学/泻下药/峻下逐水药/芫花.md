# 芫花

> [!info] 速记
> 泻水逐饮、祛痰止咳为要

## 性味归经
- 性味：苦、辛，温；有毒
- 归经：肺、脾、肾经

## 功效
- 泻水逐饮
- 祛痰止咳
- 杀虫疗疮

## 主治
- 胸胁停饮，水肿鼓胀
- 咳嗽痰喘
- 头疮、白秃、顽癣

## 用法用量
- 煎服，1.5～3g；入丸散服，每次0.6g；外用适量

## 禁忌
- 有毒，孕妇禁用；不宜与甘草同用
