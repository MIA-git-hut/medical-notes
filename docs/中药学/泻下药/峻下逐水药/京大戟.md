# 京大戟

> [!info] 速记
> 泻水逐饮、消肿散结为要

## 性味归经
- 性味：苦，寒；有毒
- 归经：肺、脾、肾经

## 功效
- 泻水逐饮
- 消肿散结

## 主治
- 水肿胀满，胸腹积水
- 痰饮积聚
- 痈肿疮毒，瘰疬痰核

## 用法用量
- 煎服，1.5～3g；入丸散服，每次1g

## 禁忌
- 有毒，孕妇禁用；体虚者慎用；不宜与甘草同用
