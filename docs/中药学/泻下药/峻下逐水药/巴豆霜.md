# 巴豆霜

> [!info] 速记
> 峻下冷积、逐水退肿为要

## 性味归经
- 性味：辛，热；大毒
- 归经：胃、大肠经

## 功效
- 峻下冷积
- 逐水退肿
- 豁痰利咽
- 外用蚀疮

## 主治
- 寒积便秘，腹满胀痛
- 喉痹痰阻
- 寒实结胸
- 恶疮疥癣

## 用法用量
- 入丸散服，0.1～0.3g；外用适量

## 禁忌
- 大毒，孕妇禁用；不宜与牵牛子同用
