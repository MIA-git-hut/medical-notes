# 甘遂

> [!info] 速记
> 泻水逐饮、消肿散结为要

## 性味归经
- 性味：苦，寒；有毒
- 归经：肺、肾、大肠经

## 功效
- 泻水逐饮
- 消肿散结

## 主治
- 水肿，鼓胀，胸胁停饮
- 风痰癫痫
- 疮痈肿毒

## 用法用量
- 入丸散服，0.5～1g；醋制可降低毒性

## 禁忌
- 有毒，孕妇禁用；体虚者忌用；不宜与甘草同用
