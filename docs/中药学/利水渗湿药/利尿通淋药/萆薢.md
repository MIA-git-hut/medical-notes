# 萆薢

> [!info] 速记
> 利湿去浊、祛风除痹为要

## 性味归经
- 性味：苦，平
- 归经：肾、胃经

## 功效
- 利湿去浊
- 祛风除痹

## 主治
- 膏淋，白浊，白带过多
- 风湿痹痛，关节不利

## 用法用量
- 煎服，9～15g

## 禁忌
- 肾阴亏虚者慎用
