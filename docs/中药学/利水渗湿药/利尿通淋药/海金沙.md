# 海金沙

> [!info] 速记
> 清利湿热、通淋止痛为要

## 性味归经
- 性味：甘、咸，寒
- 归经：膀胱、小肠经

## 功效
- 清利湿热
- 通淋止痛

## 主治
- 热淋，石淋，血淋，膏淋，尿道涩痛

## 用法用量
- 煎服，6～15g，包煎

## 禁忌
- 肾阴亏虚者慎用
