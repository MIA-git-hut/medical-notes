# 地肤子

> [!info] 速记
> 清热利湿、祛风止痒为要

## 性味归经
- 性味：辛、苦，寒
- 归经：肾、膀胱经

## 功效
- 清热利湿
- 祛风止痒

## 主治
- 热淋涩痛
- 风疹湿疹，皮肤瘙痒，阴痒

## 用法用量
- 煎服，9～15g；外用适量

- 无明显禁忌
