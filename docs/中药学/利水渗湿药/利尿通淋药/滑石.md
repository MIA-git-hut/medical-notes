# 滑石

> [!info] 速记
> 利尿通淋、清热解暑为要

## 性味归经
- 性味：甘、淡，寒
- 归经：膀胱、肺、胃经

## 功效
- 利尿通淋
- 清热解暑
- 祛湿敛疮

## 主治
- 热淋，石淋，尿热涩痛
- 暑湿烦渴，湿温初起
- 湿疹湿疮，痱子

## 用法用量
- 煎服，10～20g，包煎；外用适量

## 禁忌
- 脾虚、热病伤津及孕妇慎用
