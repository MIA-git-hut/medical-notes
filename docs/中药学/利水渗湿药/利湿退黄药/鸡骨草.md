# 鸡骨草

> [!info] 速记
> 利湿退黄、清热解毒为要

## 性味归经
- 性味：甘、微苦，凉
- 归经：肝、胃经

## 功效
- 利湿退黄
- 清热解毒
- 疏肝止痛

## 主治
- 湿热黄疸
- 胁肋不舒，胃脘疼痛

## 用法用量
- 煎服，15～30g

## 禁忌
- 无明显禁忌
