# 茵陈

> [!info] 速记
> 清利湿热、利胆退黄为要

## 性味归经
- 性味：苦、辛，微寒
- 归经：脾、胃、肝、胆经

## 功效
- 清利湿热
- 利胆退黄

## 主治
- 黄疸尿少
- 湿温暑湿
- 湿疮瘙痒

## 用法用量
- 煎服，6～15g；外用适量

## 禁忌
- 蓄血发黄及血虚萎黄者慎用
