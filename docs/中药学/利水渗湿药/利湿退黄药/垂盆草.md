# 垂盆草

> [!info] 速记
> 利湿退黄、清热解毒为要

## 性味归经
- 性味：甘、淡，凉
- 归经：肝、胆、小肠经

## 功效
- 利湿退黄
- 清热解毒

## 主治
- 湿热黄疸
- 痈肿疮疡，毒蛇咬伤
- 水火烫伤

## 用法用量
- 煎服，15～30g；外用适量

## 禁忌
- 无明显禁忌
