# 虎杖

> [!info] 速记
> 利湿退黄、清热解毒为要

## 性味归经
- 性味：微苦，微寒
- 归经：肝、胆、肺经

## 功效
- 利湿退黄
- 清热解毒
- 散瘀止痛
- 止咳化痰

## 主治
- 湿热黄疸，淋浊带下
- 水火烫伤，痈肿疮毒
- 经闭癥瘕，跌打损伤
- 肺热咳嗽

## 用法用量
- 煎服，9～15g

## 禁忌
- 孕妇慎用
