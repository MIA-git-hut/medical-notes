# 金钱草

> [!info] 速记
> 利湿退黄、利尿通淋为要

## 性味归经
- 性味：甘、咸，微寒
- 归经：肝、胆、肾、膀胱经

## 功效
- 利湿退黄
- 利尿通淋
- 解毒消肿

## 主治
- 湿热黄疸
- 石淋，热淋
- 痈肿疔疮，毒蛇咬伤

## 用法用量
- 煎服，15～60g；外用适量

## 禁忌
- 无明显禁忌
