# 猪苓

> [!info] 速记
> 利水渗湿为要

## 性味归经
- 性味：甘、淡，平
- 归经：肾、膀胱经

## 功效
- 利水渗湿

## 主治
- 水肿，小便不利，泄泻，淋浊，带下

## 用法用量
- 煎服，6～12g

## 禁忌
- 无水湿者忌用
