# 泽泻

> [!info] 速记
> 利水渗湿、泄热为要

## 性味归经
- 性味：甘、淡，寒
- 归经：肾、膀胱经

## 功效
- 利水渗湿
- 泄热
- 化浊降脂

## 主治
- 水肿胀满，小便不利，泄泻尿少
- 痰饮眩晕
- 热淋涩痛，高脂血症

## 用法用量
- 煎服，6～10g

## 禁忌
- 肾虚精滑无湿热者慎用
