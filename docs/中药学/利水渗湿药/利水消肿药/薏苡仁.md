# 薏苡仁

> [!info] 速记
> 利水渗湿、健脾止泻为要

## 性味归经
- 性味：甘、淡，凉
- 归经：脾、胃、肺经

## 功效
- 利水渗湿
- 健脾止泻
- 除痹
- 排脓
- 解毒散结

## 主治
- 水肿，脚气
- 脾虚泄泻
- 风湿痹痛，筋脉拘挛
- 肺痈，肠痈
- 赘疣、癌肿

## 用法用量
- 煎服，9～30g；清利湿热宜生用，健脾止泻宜炒用

## 禁忌
- 孕妇慎用；津液不足者慎用
