# 茯苓

> [!info] 速记
> 利水渗湿、健脾为要

## 性味归经
- 性味：甘、淡，平
- 归经：心、肺、脾、肾经

## 功效
- 利水渗湿
- 健脾
- 宁心安神

## 主治
- 水肿尿少
- 痰饮眩悸
- 脾虚食少，便溏泄泻
- 心神不安，惊悸失眠

## 用法用量
- 煎服，10～15g

## 禁忌
- 虚寒精滑者忌服
