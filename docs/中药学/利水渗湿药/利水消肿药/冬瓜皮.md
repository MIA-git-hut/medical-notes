# 冬瓜皮

> [!info] 速记
> 利水消肿、清热解暑为要

## 性味归经
- 性味：甘，凉
- 归经：脾、小肠经

## 功效
- 利水消肿
- 清热解暑

## 主治
- 水肿胀满，小便不利
- 暑热口渴，小便短赤

## 用法用量
- 煎服，9～30g

## 禁忌
- 无明显禁忌
