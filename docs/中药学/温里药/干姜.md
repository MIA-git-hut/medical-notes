# 干姜

> [!info] 速记
> 温中散寒、回阳通脉为要

## 性味归经
- 性味：辛，热
- 归经：脾、胃、肾、心、肺经

## 功效
- 温中散寒
- 回阳通脉
- 温肺化饮

## 主治
- 脘腹冷痛，呕吐泄泻
- 亡阳证
- 寒饮喘咳

## 用法用量
- 煎服，3～10g

## 禁忌
- 阴虚内热、血热妄行者忌用；孕妇慎用
