# 吴茱萸

> [!info] 速记
> 散寒止痛、降逆止呕为要

## 性味归经
- 性味：辛、苦，热；有小毒
- 归经：肝、脾、胃、肾经

## 功效
- 散寒止痛
- 降逆止呕
- 助阳止泻

## 主治
- 寒凝疼痛，厥阴头痛，寒疝腹痛，痛经
- 胃寒呕吐
- 虚寒泄泻，五更泄泻

## 用法用量
- 煎服，2～5g；外用适量

## 禁忌
- 有小毒，不宜多服久服；阴虚有热者忌用
