# 附子

> [!info] 速记
> 回阳救逆、补火助阳为要

## 性味归经
- 性味：辛、甘，大热；有毒
- 归经：心、肾、脾经

## 功效
- 回阳救逆
- 补火助阳
- 散寒止痛

## 主治
- 亡阳虚脱，肢冷脉微
- 阳痿宫冷，心腹冷痛，虚寒吐泻，寒疝腹痛
- 阴寒水肿，阳虚外感
- 寒湿痹痛

## 用法用量
- 煎服，3～15g，先煎0.5～1小时，至口尝无麻辣感

## 禁忌
- 有毒，孕妇禁用；不宜与半夏、瓜蒌、贝母、白蔹、白及同用
