# 丁香

> [!info] 速记
> 温中降逆、散寒止痛为要

## 性味归经
- 性味：辛，温
- 归经：脾、胃、肺、肾经

## 功效
- 温中降逆
- 散寒止痛
- 温肾助阳

## 主治
- 胃寒呕吐，呃逆
- 脘腹冷痛
- 阳痿，宫冷

## 用法用量
- 煎服，1～3g

## 禁忌
- 热证及阴虚内热者忌用；不宜与郁金同用
