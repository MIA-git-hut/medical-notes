# 胡椒

> [!info] 速记
> 温中散寒、下气消痰为要

## 性味归经
- 性味：辛，热
- 归经：胃、大肠经

## 功效
- 温中散寒
- 下气消痰

## 主治
- 胃寒腹痛，呕吐泄泻
- 癫痫痰多

## 用法用量
- 煎服，0.6～1.5g，研粉吞服

## 禁忌
- 阴虚有热者忌用
