# 石菖蒲

> [!info] 速记
> 开窍豁痰、醒神益智为要

## 性味归经
- 性味：辛、苦，温
- 归经：心、胃经

## 功效
- 开窍豁痰
- 醒神益智
- 化湿开胃

## 主治
- 痰蒙清窍，神昏癫痫，健忘失眠
- 耳鸣耳聋
- 脘痞不饥，噤口下痢

## 用法用量
- 煎服，3～10g；鲜品加倍

## 禁忌
- 阴虚阳亢、烦躁汗多、滑精者慎用
