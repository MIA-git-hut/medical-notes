# 麝香

> [!info] 速记
> 开窍醒神、活血通经为要

## 性味归经
- 性味：辛，温
- 归经：心、脾经

## 功效
- 开窍醒神
- 活血通经
- 消肿止痛

## 主治
- 热病神昏，中风痰厥，气郁暴厥，中恶昏迷
- 经闭癥瘕，难产死胎
- 胸痹心痛，心腹暴痛
- 跌打损伤，痹痛，疮疡肿毒

## 用法用量
- 入丸散，0.03～0.1g；不入煎剂；外用适量

## 禁忌
- 孕妇禁用；虚脱证禁用
