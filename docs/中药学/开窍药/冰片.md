# 冰片

> [!info] 速记
> 开窍醒神、清热止痛为要

## 性味归经
- 性味：辛、苦，微寒
- 归经：心、脾、肺经

## 功效
- 开窍醒神
- 清热止痛

## 主治
- 热病神昏，中风痰厥，中恶昏迷
- 目赤肿痛，咽喉肿痛，口疮
- 疮疡肿痛，烧烫伤

## 用法用量
- 入丸散，0.15～0.3g；外用适量，研粉点敷患处

## 禁忌
- 孕妇慎用；气血虚衰者慎用
