# 芡实

> [!info] 速记
> 益肾固精、补脾止泻为要

## 性味归经
- 性味：甘、涩，平
- 归经：脾、肾经

## 功效
- 益肾固精
- 补脾止泻
- 除湿止带

## 主治
- 肾虚遗精滑精，遗尿尿频
- 脾虚久泻
- 白浊，带下

## 用法用量
- 煎服，9～15g

## 禁忌
- 大小便不利者慎用
