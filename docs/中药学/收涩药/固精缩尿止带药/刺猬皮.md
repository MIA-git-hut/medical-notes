# 刺猬皮

> [!info] 速记
> 固精缩尿、收敛止血为要

## 性味归经
- 性味：苦、涩，平
- 归经：肾、胃、大肠经

## 功效
- 固精缩尿
- 收敛止血
- 化瘀止痛

## 主治
- 遗精滑精，遗尿尿频
- 便血，痔血，崩漏
- 胃脘疼痛

## 用法用量
- 煎服，3～10g；研末服，1.5～3g

## 禁忌
- 孕妇慎用
