# 鸡冠花

> [!info] 速记
> 收敛止血、止带为要

## 性味归经
- 性味：甘、涩，凉
- 归经：肝、大肠经

## 功效
- 收敛止血
- 止带
- 止痢

## 主治
- 吐血衄血，崩漏便血，痔血
- 赤白带下
- 久痢不止

## 用法用量
- 煎服，6～12g

## 禁忌
- 瘀血阻滞者慎用
