# 莲子

> [!info] 速记
> 补脾止泻、止带为要

## 性味归经
- 性味：甘、涩，平
- 归经：脾、肾、心经

## 功效
- 补脾止泻
- 止带
- 益肾涩精
- 养心安神

## 主治
- 脾虚久泻，食欲不振
- 肾虚遗精，带下
- 心悸失眠

## 用法用量
- 煎服，6～15g；去心用

## 禁忌
- 中满痞胀、大便燥结者忌用
