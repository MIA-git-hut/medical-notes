# 桑螵蛸

> [!info] 速记
> 固精缩尿、补肾助阳为要

## 性味归经
- 性味：甘、咸，平
- 归经：肝、肾经

## 功效
- 固精缩尿
- 补肾助阳

## 主治
- 遗精滑精，遗尿尿频，小便白浊
- 肾虚阳痿

## 用法用量
- 煎服，5～10g

## 禁忌
- 阴虚火旺、膀胱湿热者忌用
