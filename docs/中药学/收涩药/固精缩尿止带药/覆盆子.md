# 覆盆子

> [!info] 速记
> 益肾固精缩尿、养肝明目为要

## 性味归经
- 性味：甘、酸，温
- 归经：肝、肾、膀胱经

## 功效
- 益肾固精缩尿
- 养肝明目

## 主治
- 遗精滑精，遗尿尿频
- 阳痿早泄，目暗昏花

## 用法用量
- 煎服，6～12g

## 禁忌
- 肾虚有火、小便短涩者慎用
