# 山茱萸

> [!info] 速记
> 补益肝肾、收涩固脱为要

## 性味归经
- 性味：酸、涩，微温
- 归经：肝、肾经

## 功效
- 补益肝肾
- 收涩固脱

## 主治
- 眩晕耳鸣，腰膝酸痛，阳痿遗精，遗尿尿频
- 大汗不止，体虚欲脱
- 崩漏带下

## 用法用量
- 煎服，6～12g；急救固脱可用20～30g

## 禁忌
- 素有湿热、小便淋涩者慎用
