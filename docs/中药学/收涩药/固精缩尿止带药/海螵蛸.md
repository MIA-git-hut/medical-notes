# 海螵蛸

> [!info] 速记
> 收敛止血、涩精止带为要

## 性味归经
- 性味：咸、涩，温
- 归经：脾、肾经

## 功效
- 收敛止血
- 涩精止带
- 制酸止痛
- 收湿敛疮

## 主治
- 吐血衄血，崩漏便血，外伤出血
- 遗精滑精，赤白带下
- 胃痛吞酸
- 湿疮湿疹，溃疡不敛（外用）

## 用法用量
- 煎服，6～12g；研末吞服，每次1.5～3g；外用适量

## 禁忌
- 阴虚多热者慎用；大剂量可致便秘
