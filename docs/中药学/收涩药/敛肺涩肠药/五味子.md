# 五味子

> [!info] 速记
> 收敛固涩、益气生津为要

## 性味归经
- 性味：酸、甘，温
- 归经：肺、心、肾经

## 功效
- 收敛固涩
- 益气生津
- 补肾宁心

## 主治
- 久嗽虚喘
- 梦遗滑精，遗尿尿频
- 久泻不止
- 自汗盗汗
- 津伤口渴，内热消渴
- 心悸失眠

## 用法用量
- 煎服，2～6g；研末服，每次1～3g

## 禁忌
- 表邪未解、内有实热、咳嗽初起、麻疹初发者忌用
