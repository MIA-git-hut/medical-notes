# 五倍子

> [!info] 速记
> 敛肺降火、涩肠止泻为要

## 性味归经
- 性味：酸、涩，寒
- 归经：肺、大肠、肾经

## 功效
- 敛肺降火
- 涩肠止泻
- 敛汗止血
- 收湿敛疮

## 主治
- 肺虚久咳，肺热痰嗽
- 久泻久痢
- 自汗盗汗
- 各种出血
- 疮疡肿毒，湿疮流水（外用）

## 用法用量
- 煎服，3～6g；研末服，每次1～1.5g；外用适量

## 禁忌
- 湿热泻痢者忌用
