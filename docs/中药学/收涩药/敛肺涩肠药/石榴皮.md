# 石榴皮

> [!info] 速记
> 涩肠止泻、止血为要

## 性味归经
- 性味：酸、涩，温
- 归经：大肠经

## 功效
- 涩肠止泻
- 止血
- 驱虫

## 主治
- 久泻久痢，便血脱肛
- 崩漏带下
- 虫积腹痛

## 用法用量
- 煎服，3～10g；止血炒炭用

## 禁忌
- 泻痢初起、实邪未清者忌用；大剂量可致中毒
