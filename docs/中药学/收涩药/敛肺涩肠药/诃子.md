# 诃子

> [!info] 速记
> 涩肠止泻、敛肺止咳为要

## 性味归经
- 性味：苦、酸、涩，平
- 归经：肺、大肠经

## 功效
- 涩肠止泻
- 敛肺止咳
- 降火利咽

## 主治
- 久泻久痢，便血脱肛
- 肺虚喘咳，久咳失音

## 用法用量
- 煎服，3～10g；涩肠止泻宜煨用，敛肺利咽宜生用

## 禁忌
- 外邪未解、内有湿热积滞者慎用
