# 罂粟壳

> [!info] 速记
> 敛肺、涩肠为要

## 性味归经
- 性味：酸、涩，平；有毒
- 归经：肺、大肠、肾经

## 功效
- 敛肺
- 涩肠
- 止痛

## 主治
- 久咳虚喘
- 久泻久痢
- 心腹及筋骨疼痛

## 用法用量
- 煎服，3～6g；蜜炙或醋炒用

## 禁忌
- 有毒，易成瘾，不宜常服；咳嗽初起、积滞泻痢者忌用；孕妇、儿童禁用
