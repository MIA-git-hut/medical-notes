# 白芥子

> [!info] 速记
> 温肺化痰、利气散结为要

## 性味归经
- 性味：辛，温
- 归经：肺、胃经

## 功效
- 温肺化痰
- 利气散结
- 通络止痛

## 主治
- 寒痰喘咳，悬饮胸胁胀痛
- 痰滞经络，肢体麻木疼痛
- 阴疽流注

## 用法用量
- 煎服，3～6g；外用适量

## 禁忌
- 外敷易起泡；肺虚久咳、阴虚火旺者忌用
