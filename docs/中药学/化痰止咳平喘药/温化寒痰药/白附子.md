# 白附子

> [!info] 速记
> 祛风痰、定惊搐为要

## 性味归经
- 性味：辛，温；有毒
- 归经：胃、肝经

## 功效
- 祛风痰
- 定惊搐
- 解毒散结
- 止痛

## 主治
- 中风痰壅，口眼歪斜，惊风癫痫，破伤风
- 痰厥头痛
- 瘰疬痰核，毒蛇咬伤（外用）

## 用法用量
- 煎服，3～6g（制用）；外用生品适量

## 禁忌
- 有毒，孕妇忌用；阴虚血虚动风者慎用
