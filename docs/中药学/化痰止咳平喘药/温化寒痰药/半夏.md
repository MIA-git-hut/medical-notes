# 半夏

> [!info] 速记
> 燥湿化痰、降逆止呕为要

## 性味归经
- 性味：辛，温；有毒
- 归经：脾、胃、肺经

## 功效
- 燥湿化痰
- 降逆止呕
- 消痞散结
- 外用消肿止痛

## 主治
- 湿痰寒痰，咳喘痰多
- 呕吐反胃
- 胸脘痞闷，梅核气
- 瘿瘤痰核，痈疽肿毒（外用）

## 用法用量
- 煎服，3～9g；内服须炮制（法半夏、姜半夏等）；生品外用适量

## 禁忌
- 有毒，阴虚燥咳、血证、热痰燥痰者慎用；不宜与乌头类同用；孕妇慎用
