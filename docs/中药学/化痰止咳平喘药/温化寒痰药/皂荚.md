# 皂荚

> [!info] 速记
> 祛顽痰、通窍开闭为要

## 性味归经
- 性味：辛、咸，温；有小毒
- 归经：肺、大肠经

## 功效
- 祛顽痰
- 通窍开闭
- 祛风杀虫

## 主治
- 顽痰阻肺，咳喘痰多
- 中风痰厥，癫痫
- 便秘
- 疮癣（外用）

## 用法用量
- 煎服，1～1.5g；焙焦研末服，0.6～1.5g；外用适量

## 禁忌
- 有小毒，孕妇、咯血及体虚者忌用
