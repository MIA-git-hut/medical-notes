# 天南星

> [!info] 速记
> 燥湿化痰、祛风止痉为要

## 性味归经
- 性味：苦、辛，温；有毒
- 归经：肺、肝、脾经

## 功效
- 燥湿化痰
- 祛风止痉
- 外用散结消肿

## 主治
- 顽痰咳嗽，风痰眩晕，中风痰壅，癫痫惊风
- 破伤风
- 痈肿痰核（外用）

## 用法用量
- 煎服，3～9g（制用）；生品外用适量

## 禁忌
- 有毒，孕妇忌用；阴虚燥痰者慎用
