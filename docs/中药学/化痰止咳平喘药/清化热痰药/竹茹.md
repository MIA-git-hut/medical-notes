# 竹茹

> [!info] 速记
> 清热化痰、除烦止呕为要

## 性味归经
- 性味：甘，微寒
- 归经：肺、胃、心、胆经

## 功效
- 清热化痰
- 除烦止呕

## 主治
- 痰热咳嗽，痰黄黏稠
- 心烦不眠
- 胃热呕吐，妊娠恶阻
- 吐血衄血

## 用法用量
- 煎服，5～10g；除烦止呕宜姜汁炙用

## 禁忌
- 胃寒呕吐、寒痰者慎用
