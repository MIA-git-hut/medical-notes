# 浙贝母

> [!info] 速记
> 清热化痰止咳、解毒散结消痈为要

## 性味归经
- 性味：苦，寒
- 归经：肺、心经

## 功效
- 清热化痰止咳
- 解毒散结消痈

## 主治
- 风热咳嗽，痰热咳嗽
- 瘰疬瘿瘤，乳痈疮毒，肺痈

## 用法用量
- 煎服，5～10g

## 禁忌
- 不宜与乌头类同用；寒痰、湿痰者慎用
