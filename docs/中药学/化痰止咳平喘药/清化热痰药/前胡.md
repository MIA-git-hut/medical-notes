# 前胡

> [!info] 速记
> 降气化痰、散风清热为要

## 性味归经
- 性味：苦、辛，微寒
- 归经：肺经

## 功效
- 降气化痰
- 散风清热

## 主治
- 痰热咳喘，痰黄黏稠
- 风热咳嗽痰多

## 用法用量
- 煎服，3～10g

## 禁忌
- 阴虚咳嗽、寒痰咳嗽者慎用
