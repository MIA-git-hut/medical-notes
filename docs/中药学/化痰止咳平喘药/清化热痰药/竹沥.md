# 竹沥

> [!info] 速记
> 清热豁痰、定惊利窍为要

## 性味归经
- 性味：甘，寒
- 归经：心、肺、肝经

## 功效
- 清热豁痰
- 定惊利窍

## 主治
- 痰热咳嗽，痰黄黏稠难咯
- 中风痰迷，惊痫癫狂

## 用法用量
- 冲服，30～50ml；入丸剂

## 禁忌
- 寒痰、便溏者忌用
