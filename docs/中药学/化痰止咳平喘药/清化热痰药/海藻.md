# 海藻

> [!info] 速记
> 消痰软坚散结、利水消肿为要

## 性味归经
- 性味：苦、咸，寒
- 归经：肝、胃、肾经

## 功效
- 消痰软坚散结
- 利水消肿

## 主治
- 瘿瘤瘰疬，睾丸肿痛
- 痰饮水肿

## 用法用量
- 煎服，6～12g

## 禁忌
- 不宜与甘草同用；脾胃虚寒者慎用
