# 礞石

> [!info] 速记
> 坠痰下气、平肝镇惊为要

## 性味归经
- 性味：甘、咸，平
- 归经：肺、心、肝经

## 功效
- 坠痰下气
- 平肝镇惊

## 主治
- 顽痰胶结，咳逆喘急
- 癫狂惊痫，烦躁胸闷

## 用法用量
- 入丸散，3～6g；煎服，10～15g，布包先煎

## 禁忌
- 孕妇及脾胃虚弱者忌用
