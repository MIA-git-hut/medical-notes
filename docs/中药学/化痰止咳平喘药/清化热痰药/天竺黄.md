# 天竺黄

> [!info] 速记
> 清热豁痰、凉心定惊为要

## 性味归经
- 性味：甘，寒
- 归经：心、肝经

## 功效
- 清热豁痰
- 凉心定惊

## 主治
- 热病神昏，中风痰迷
- 小儿痰热惊痫，夜啼

## 用法用量
- 煎服，3～9g；研粉冲服，每次0.6～1g

## 禁忌
- 寒痰者慎用
