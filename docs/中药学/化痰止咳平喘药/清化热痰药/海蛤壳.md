# 海蛤壳

> [!info] 速记
> 清热化痰、软坚散结为要

## 性味归经
- 性味：苦、咸，寒
- 归经：肺、胃经

## 功效
- 清热化痰
- 软坚散结
- 制酸止痛
- 外用收湿敛疮

## 主治
- 痰热咳嗽，痰黄黏稠
- 瘿瘤瘰疬
- 胃痛泛酸
- 湿疹烫伤（外用）

## 用法用量
- 煎服，6～15g，蛤粉宜包煎；外用适量

## 禁忌
- 脾胃虚寒者慎用
