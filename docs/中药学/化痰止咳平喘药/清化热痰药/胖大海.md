# 胖大海

> [!info] 速记
> 清热润肺、利咽开音为要

## 性味归经
- 性味：甘，寒
- 归经：肺、大肠经

## 功效
- 清热润肺
- 利咽开音
- 润肠通便

## 主治
- 肺热声哑，咽喉干痛，干咳无痰
- 热结便秘

## 用法用量
- 沸水泡服或煎服，2～4枚

## 禁忌
- 脾胃虚寒、便溏者慎用
