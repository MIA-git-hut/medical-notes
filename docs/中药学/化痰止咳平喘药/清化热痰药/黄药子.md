# 黄药子

> [!info] 速记
> 化痰散结消瘿、清热解毒为要

## 性味归经
- 性味：苦，寒；有毒
- 归经：肺、肝、心经

## 功效
- 化痰散结消瘿
- 清热解毒

## 主治
- 瘿瘤瘰疬
- 疮疡肿毒，咽喉肿痛，毒蛇咬伤

## 用法用量
- 煎服，5～15g；外用适量

## 禁忌
- 有毒，不宜过量久服；肝肾功能不全者慎用
