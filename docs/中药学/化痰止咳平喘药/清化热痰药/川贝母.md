# 川贝母

> [!info] 速记
> 清热润肺、化痰止咳为要

## 性味归经
- 性味：苦、甘，微寒
- 归经：肺、心经

## 功效
- 清热润肺
- 化痰止咳
- 散结消痈

## 主治
- 肺热燥咳，干咳少痰，阴虚劳嗽，咯痰带血
- 瘰疬、乳痈、肺痈

## 用法用量
- 煎服，3～10g；研粉冲服，每次1～2g

## 禁忌
- 不宜与乌头类同用；脾胃虚寒及痰湿盛者慎用
