# 洋金花

> [!info] 速记
> 平喘止咳、解痉定痛为要

## 性味归经
- 性味：辛，温；有毒
- 归经：肺、肝经

## 功效
- 平喘止咳
- 解痉定痛

## 主治
- 哮喘咳嗽
- 脘腹冷痛，风湿痹痛，小儿慢惊

## 用法用量
- 内服入丸散，0.3～0.6g；外用适量

## 禁忌
- 有毒，青光眼、高血压、心动过速者忌用；外感痰热咳喘者忌用
