# 白果

> [!info] 速记
> 敛肺定喘、止带缩尿为要

## 性味归经
- 性味：甘、苦、涩，平；有毒
- 归经：肺、肾经

## 功效
- 敛肺定喘
- 止带缩尿

## 主治
- 哮喘痰嗽
- 带下白浊
- 遗尿尿频

## 用法用量
- 煎服，5～10g，捣碎

## 禁忌
- 有毒，生食易中毒，不可过量；咳嗽痰稠不利者慎用
