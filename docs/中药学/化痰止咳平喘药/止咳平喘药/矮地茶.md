# 矮地茶

> [!info] 速记
> 止咳平喘、清利湿热为要

## 性味归经
- 性味：辛、微苦，平
- 归经：肺、肝经

## 功效
- 止咳平喘
- 清利湿热
- 活血化瘀

## 主治
- 咳嗽气喘
- 湿热黄疸
- 血瘀经闭，跌打损伤

## 用法用量
- 煎服，10～30g

- 无明显禁忌
