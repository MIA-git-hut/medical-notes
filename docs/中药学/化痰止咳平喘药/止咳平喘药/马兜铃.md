# 马兜铃

> [!info] 速记
> 清肺降气、止咳平喘为要

## 性味归经
- 性味：苦，微寒
- 归经：肺、大肠经

## 功效
- 清肺降气
- 止咳平喘
- 清肠消痔

## 主治
- 肺热咳喘，痰中带血
- 痔疮肿痛，肠热痔血

## 用法用量
- 煎服，3～9g

## 禁忌
- 含马兜铃酸，肾毒性大，内服宜慎、不宜过量久服；肾功能不全者禁用
