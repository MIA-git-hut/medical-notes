# 罗汉果

> [!info] 速记
> 清热润肺、利咽开音为要

## 性味归经
- 性味：甘，凉
- 归经：肺、大肠经

## 功效
- 清热润肺
- 利咽开音
- 滑肠通便

## 主治
- 肺热燥咳，咽痛失音
- 肠燥便秘

## 用法用量
- 煎服或开水泡服，9～15g

## 禁忌
- 无明显禁忌
