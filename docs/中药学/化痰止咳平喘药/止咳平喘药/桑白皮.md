# 桑白皮

> [!info] 速记
> 泻肺平喘、利水消肿为要

## 性味归经
- 性味：甘，寒
- 归经：肺经

## 功效
- 泻肺平喘
- 利水消肿

## 主治
- 肺热喘咳
- 水肿胀满，小便不利

## 用法用量
- 煎服，6～12g；泻肺利水宜生用，肺虚咳嗽宜蜜炙

## 禁忌
- 肺虚无火、风寒咳嗽者慎用
