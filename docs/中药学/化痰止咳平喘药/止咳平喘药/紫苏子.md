# 紫苏子

> [!info] 速记
> 降气化痰、止咳平喘为要

## 性味归经
- 性味：辛，温
- 归经：肺、大肠经

## 功效
- 降气化痰
- 止咳平喘
- 润肠通便

## 主治
- 痰壅气逆，咳嗽气喘
- 肠燥便秘

## 用法用量
- 煎服，3～10g

## 禁忌
- 阴虚喘咳、脾虚便溏者慎用
