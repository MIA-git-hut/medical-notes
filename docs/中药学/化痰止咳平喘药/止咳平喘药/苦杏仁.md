# 苦杏仁

> [!info] 速记
> 降气止咳平喘、润肠通便为要

## 性味归经
- 性味：苦，微温；有小毒
- 归经：肺、大肠经

## 功效
- 降气止咳平喘
- 润肠通便

## 主治
- 咳嗽气喘，胸满痰多
- 肠燥便秘

## 用法用量
- 煎服，5～10g，打碎后下

## 禁忌
- 有小毒，用量不宜过大；阴虚咳喘、大便溏泄者慎用
