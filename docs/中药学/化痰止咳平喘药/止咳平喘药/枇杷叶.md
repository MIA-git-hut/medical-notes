# 枇杷叶

> [!info] 速记
> 清肺止咳、降逆止呕为要

## 性味归经
- 性味：苦，微寒
- 归经：肺、胃经

## 功效
- 清肺止咳
- 降逆止呕

## 主治
- 肺热咳嗽，气逆喘急
- 胃热呕逆，烦热口渴

## 用法用量
- 煎服，6～10g；止咳宜蜜炙，止呕宜生用

## 禁忌
- 胃寒呕吐、寒咳者慎用
