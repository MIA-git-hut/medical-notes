# 百部

> [!info] 速记
> 润肺下气止咳、杀虫灭虱为要

## 性味归经
- 性味：甘、苦，微温
- 归经：肺经

## 功效
- 润肺下气止咳
- 杀虫灭虱

## 主治
- 新久咳嗽，百日咳，肺痨咳嗽
- 蛲虫病，头虱体虱（外用）

## 用法用量
- 煎服，3～9g；蜜炙百部润肺止咳

## 禁忌
- 无明显禁忌
