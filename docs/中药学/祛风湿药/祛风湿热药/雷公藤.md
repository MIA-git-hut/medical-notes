# 雷公藤

> [!info] 速记
> 祛风除湿、活血通络为要

## 性味归经
- 性味：苦、辛，寒；大毒
- 归经：心、肝经

## 功效
- 祛风除湿
- 活血通络
- 消肿止痛
- 杀虫解毒

## 主治
- 风湿顽痹，关节肿痛
- 疔疮肿毒
- 腰带疮

## 用法用量
- 煎服，6～10g，久煎；外用适量

## 禁忌
- 大毒，内服宜慎；孕妇、育龄期男女、肝肾功能不全者禁用
