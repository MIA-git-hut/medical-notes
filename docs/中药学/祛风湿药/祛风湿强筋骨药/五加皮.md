# 五加皮

> [!info] 速记
> 祛风除湿、补益肝肾为要

## 性味归经
- 性味：辛、苦，温
- 归经：肝、肾经

## 功效
- 祛风除湿
- 补益肝肾
- 强筋壮骨
- 利水消肿

## 主治
- 风湿痹痛，筋脉拘挛
- 肝肾不足，筋骨痿软，小儿行迟
- 水肿，脚气浮肿

## 用法用量
- 煎服，5～10g

## 禁忌
- 阴虚火旺者慎用
