# 川乌

> [!info] 速记
> 祛风除湿、温经止痛为要

## 性味归经
- 性味：辛、苦，热；有大毒
- 归经：心、肝、肾、脾经

## 功效
- 祛风除湿
- 温经止痛

## 主治
- 风寒湿痹，关节疼痛
- 心腹冷痛，寒疝腹痛
- 麻醉止痛

## 用法用量
- 煎服，1.5～3g，先煎久煎（1～2小时）；入丸散，0.5～1g；须炮制后用

## 禁忌
- 有大毒，孕妇禁用；不宜与贝母、半夏、白及、白蔹、瓜蒌、天花粉同用
