# 威灵仙

> [!info] 速记
> 祛风湿、通络止痛为要

## 性味归经
- 性味：辛、咸，温
- 归经：膀胱经

## 功效
- 祛风湿
- 通络止痛
- 消骨鲠

## 主治
- 风湿痹痛，肢体麻木
- 跌打伤痛
- 诸骨鲠咽

## 用法用量
- 煎服，6～10g；治骨鲠可用30～50g煎汤或含漱

## 禁忌
- 气血虚弱者慎服
