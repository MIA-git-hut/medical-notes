# 蕲蛇

> [!info] 速记
> 祛风、通络为要

## 性味归经
- 性味：甘、咸，温；有毒
- 归经：肝经

## 功效
- 祛风
- 通络
- 止痉

## 主治
- 风湿顽痹，麻木拘挛
- 中风口眼歪斜，半身不遂
- 小儿急慢惊风，破伤风
- 麻风、疥癣

## 用法用量
- 煎服，3～9g；研末吞服，1～1.5g；或浸酒服

## 禁忌
- 有毒，血虚生风者慎用
