# 薄荷

> [!info] 速记
> 疏散风热、清利头目为要

## 性味归经
- 性味：辛，凉
- 归经：肺、肝经

## 功效
- 疏散风热
- 清利头目
- 利咽透疹
- 疏肝行气

## 主治
- 风热感冒、温病初起
- 头痛目赤、咽喉肿痛
- 麻疹不透、风疹瘙痒
- 肝郁气滞

## 用法用量
- 煎服，3～6g，后下

## 禁忌
- 体虚多汗者不宜
