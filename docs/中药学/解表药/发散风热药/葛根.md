# 葛根

> [!info] 速记
> 解肌退热、生津止渴为要

## 性味归经
- 性味：甘、辛，凉
- 归经：脾、胃、肺经

## 功效
- 解肌退热
- 生津止渴
- 透疹
- 升阳止泻
- 通经活络

## 主治
- 表证发热
- 热病口渴、消渴
- 麻疹不透
- 湿热泻痢、脾虚泄泻
- 项背强痛

## 用法用量
- 煎服，9～15g

## 禁忌
- 无明显禁忌
