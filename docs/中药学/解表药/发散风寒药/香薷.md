# 香薷

> [!info] 速记
> 发汗解表、化湿和中为要

## 性味归经
- 性味：辛，微温
- 归经：肺、胃经

## 功效
- 发汗解表
- 化湿和中
- 利水消肿

## 主治
- 暑湿感冒（阴暑）
- 水肿、小便不利

## 用法用量
- 煎服，3～10g

## 禁忌
- 表虚有汗及暑热证者忌用
