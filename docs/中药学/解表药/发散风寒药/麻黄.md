# 麻黄

> [!info] 速记
> 发汗解表、宣肺平喘为要

## 性味归经
- 性味：辛、微苦，温
- 归经：肺、膀胱经

## 功效
- 发汗解表
- 宣肺平喘
- 利水消肿

## 主治
- 风寒表实无汗证
- 咳嗽气喘
- 风水水肿

## 用法用量
- 煎服，2～10g；发汗解表宜生用，平喘止咳多蜜炙用

## 禁忌
- 表虚自汗、阴虚盗汗及肺肾虚喘者慎用；高血压、失眠者慎用
