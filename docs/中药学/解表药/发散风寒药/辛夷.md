# 辛夷

> [!info] 速记
> 散风寒、通鼻窍为要

## 性味归经
- 性味：辛，温
- 归经：肺、胃经

## 功效
- 散风寒
- 通鼻窍

## 主治
- 鼻渊、鼻塞流涕
- 风寒感冒头痛

## 用法用量
- 煎服，3～10g，包煎

## 禁忌
- 鼻病因于阴虚火旺者忌用
