# 细辛

> [!info] 速记
> 解表散寒、祛风止痛为要

## 性味归经
- 性味：辛，温；有小毒
- 归经：肺、肾、心经

## 功效
- 解表散寒
- 祛风止痛
- 通窍
- 温肺化饮

## 主治
- 风寒感冒
- 头痛、牙痛、痹痛
- 鼻渊鼻塞
- 寒痰停饮咳喘

## 用法用量
- 煎服，1～3g；散剂每次0.5～1g

## 禁忌
- 阴虚阳亢头痛、肺燥伤阴干咳者忌用；反藜芦
