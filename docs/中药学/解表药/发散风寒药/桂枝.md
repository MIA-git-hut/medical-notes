# 桂枝

> [!info] 速记
> 发汗解肌、温通经脉为要

## 性味归经
- 性味：辛、甘，温
- 归经：心、肺、膀胱经

## 功效
- 发汗解肌
- 温通经脉
- 助阳化气

## 主治
- 风寒表虚有汗证及表实无汗证
- 寒凝血滞诸痛证
- 痰饮、蓄水证
- 心悸

## 用法用量
- 煎服，3～10g

## 禁忌
- 温热病、阴虚阳盛及血热妄行者忌用，孕妇及月经过多者慎用
