# 白及

> [!info] 速记
> 收敛止血、消肿生肌为要

## 性味归经
- 性味：苦、甘、涩，微寒
- 归经：肺、胃、肝经

## 功效
- 收敛止血
- 消肿生肌

## 主治
- 咯血、吐血、衄血、外伤出血
- 疮疡肿毒，溃疡久不收口
- 肺痨咯血

## 用法用量
- 煎服，6～15g；研末吞服，3～6g；外用适量

## 禁忌
- 不宜与乌头类同用；外感咳血、肺痈初起者慎用
