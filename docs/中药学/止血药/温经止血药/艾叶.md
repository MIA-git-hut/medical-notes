# 艾叶

> [!info] 速记
> 温经止血、散寒止痛为要

## 性味归经
- 性味：辛、苦，温；有小毒
- 归经：肝、脾、肾经

## 功效
- 温经止血
- 散寒止痛
- 外用祛湿止痒

## 主治
- 虚寒性出血（崩漏、月经过多）
- 下焦虚寒，脘腹冷痛，痛经
- 湿疹瘙痒（外用）

## 用法用量
- 煎服，3～9g；外用适量，可艾灸

## 禁忌
- 有小毒，不宜过量久服；阴虚血热者慎用
