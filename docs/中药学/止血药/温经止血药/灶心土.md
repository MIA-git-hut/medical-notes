# 灶心土

> [!info] 速记
> 温中止血、止呕为要

## 性味归经
- 性味：辛，温
- 归经：脾、胃经

## 功效
- 温中止血
- 止呕
- 止泻

## 主治
- 虚寒性吐血、便血、崩漏
- 胃寒呕吐
- 脾虚久泻

## 用法用量
- 煎服，15～30g，布包先煎；或用60～120g煎汤代水

## 禁忌
- 阴虚火旺、热证出血者忌用
