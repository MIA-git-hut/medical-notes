# 三七

> [!info] 速记
> 散瘀止血、消肿定痛为要

## 性味归经
- 性味：甘、微苦，温
- 归经：肝、胃经

## 功效
- 散瘀止血
- 消肿定痛

## 主治
- 咯血、吐血、衄血、便血、崩漏、外伤出血
- 胸腹刺痛，跌打肿痛

## 用法用量
- 研末吞服，1～3g；煎服，3～9g；外用适量

## 禁忌
- 孕妇慎用；血虚无瘀者慎用
