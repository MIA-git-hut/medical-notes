# 侧柏叶

> [!info] 速记
> 凉血止血、化痰止咳为要

## 性味归经
- 性味：苦、涩，寒
- 归经：肺、肝、脾经

## 功效
- 凉血止血
- 化痰止咳
- 生发乌发

## 主治
- 血热出血证（吐血、衄血、咯血、便血、崩漏）
- 肺热咳嗽
- 血热脱发，须发早白

## 用法用量
- 煎服，6～12g；外用适量

## 禁忌
- 虚寒性出血者慎用
