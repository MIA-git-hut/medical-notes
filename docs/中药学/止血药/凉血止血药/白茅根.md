# 白茅根

> [!info] 速记
> 凉血止血、清热利尿为要

## 性味归经
- 性味：甘，寒
- 归经：肺、胃、膀胱经

## 功效
- 凉血止血
- 清热利尿

## 主治
- 血热出血证（吐血、衄血、尿血）
- 热淋，水肿，小便不利
- 热病烦渴，肺热咳嗽

## 用法用量
- 煎服，9～30g；鲜品加倍

## 禁忌
- 脾胃虚寒者慎用
