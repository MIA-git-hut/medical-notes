# 马钱子

> [!info] 速记
> 通络止痛、散结消肿为要

## 性味归经
- 性味：苦，寒；大毒
- 归经：肝、脾经

## 功效
- 通络止痛
- 散结消肿

## 主治
- 风湿顽痹，麻木瘫痪
- 跌打损伤，骨折肿痛
- 痈疽疮毒，咽喉肿痛

## 用法用量
- 制后入丸散，0.3～0.6g；外用适量

## 禁忌
- 大毒，内服须炮制且宜慎；孕妇禁用；不宜过量久服
