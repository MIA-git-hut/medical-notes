# 骨碎补

> [!info] 速记
> 疗伤止痛、补肾强骨为要

## 性味归经
- 性味：苦，温
- 归经：肝、肾经

## 功效
- 疗伤止痛
- 补肾强骨
- 外用消风祛斑

## 主治
- 跌扑闪挫，筋骨折伤
- 肾虚腰痛，耳鸣耳聋，牙齿松动
- 斑秃、白癜风（外用）

## 用法用量
- 煎服，3～9g；外用适量

## 禁忌
- 阴虚内热者慎用
