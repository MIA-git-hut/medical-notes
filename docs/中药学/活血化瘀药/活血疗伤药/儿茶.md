# 儿茶

> [!info] 速记
> 活血止痛、止血生肌为要

## 性味归经
- 性味：苦、涩，微寒
- 归经：肺、心经

## 功效
- 活血止痛
- 止血生肌
- 收湿敛疮
- 清肺化痰

## 主治
- 跌打伤痛，外伤出血
- 疮疡不敛，湿疹湿疮
- 肺热咳嗽

## 用法用量
- 煎服，1～3g，包煎；研末服，0.5～1g；外用适量

## 禁忌
- 无明显禁忌
