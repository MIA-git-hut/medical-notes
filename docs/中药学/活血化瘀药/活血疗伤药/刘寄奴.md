# 刘寄奴

> [!info] 速记
> 散瘀止痛、疗伤止血为要

## 性味归经
- 性味：苦，温
- 归经：心、肝、脾经

## 功效
- 散瘀止痛
- 疗伤止血
- 破血通经
- 消食化积

## 主治
- 跌打损伤，瘀滞肿痛
- 外伤出血
- 血瘀经闭，产后瘀阻腹痛
- 食积腹痛

## 用法用量
- 煎服，3～10g；外用适量

## 禁忌
- 孕妇忌用
