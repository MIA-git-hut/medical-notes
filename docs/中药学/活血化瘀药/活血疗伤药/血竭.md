# 血竭

> [!info] 速记
> 活血定痛、化瘀止血为要

## 性味归经
- 性味：甘、咸，平
- 归经：心、肝经

## 功效
- 活血定痛
- 化瘀止血
- 生肌敛疮

## 主治
- 跌打损伤，瘀血肿痛
- 外伤出血
- 疮疡不敛

## 用法用量
- 研末服，每次1～2g；外用适量

## 禁忌
- 孕妇及月经期慎用；无瘀血者不宜
