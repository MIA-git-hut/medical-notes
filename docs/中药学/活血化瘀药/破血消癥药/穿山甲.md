# 穿山甲

> [!info] 速记
> 活血消癥、通经下乳为要

## 性味归经
- 性味：咸，微寒
- 归经：肝、胃经

## 功效
- 活血消癥
- 通经下乳
- 消肿排脓
- 搜风通络

## 主治
- 癥瘕积聚，血瘀经闭
- 乳汁不通，产后缺乳
- 痈肿疮毒初起或脓成不溃
- 风湿痹痛，中风瘫痪

## 用法用量
- 煎服，3～10g；研末服，每次1～1.5g

## 禁忌
- 孕妇忌用；痈肿已溃者忌用
