# 斑蝥

> [!info] 速记
> 破血逐瘀、散结消癥为要

## 性味归经
- 性味：辛，热；大毒
- 归经：肝、胃、肾经

## 功效
- 破血逐瘀
- 散结消癥
- 攻毒蚀疮

## 主治
- 癥瘕积聚
- 痈疽恶疮，顽癣，瘰疬（外用为主）

## 用法用量
- 内服入丸散，0.03～0.06g；外用适量

## 禁忌
- 大毒，内服宜慎，孕妇禁用；外用不可入目
