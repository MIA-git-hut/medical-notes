# 降香

> [!info] 速记
> 化瘀止血、理气止痛为要

## 性味归经
- 性味：辛，温
- 归经：肝、脾经

## 功效
- 化瘀止血
- 理气止痛

## 主治
- 瘀血性出血证
- 胸胁刺痛，跌打损伤

## 用法用量
- 煎服，3～6g，后下；研末吞服1～2g

## 禁忌
- 阴虚火旺、血热妄行者慎用
