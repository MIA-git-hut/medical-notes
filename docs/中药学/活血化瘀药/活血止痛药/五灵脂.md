# 五灵脂

> [!info] 速记
> 活血止痛、化瘀止血为要

## 性味归经
- 性味：苦、咸、甘，温
- 归经：肝经

## 功效
- 活血止痛
- 化瘀止血

## 主治
- 瘀血阻滞诸痛（胸痹、胃脘痛、痛经、产后腹痛）
- 瘀血出血

## 用法用量
- 煎服，3～10g，包煎

## 禁忌
- 孕妇慎用；不宜与人参同用；血虚无瘀者忌用
