# 郁金

> [!info] 速记
> 活血止痛、行气解郁为要

## 性味归经
- 性味：辛、苦，寒
- 归经：肝、胆、心经

## 功效
- 活血止痛
- 行气解郁
- 清心凉血
- 利胆退黄

## 主治
- 胸胁刺痛，痛经经闭，癥瘕痞块
- 热病神昏，癫痫痰闭
- 吐血衄血，倒经
- 黄疸尿赤

## 用法用量
- 煎服，3～10g

## 禁忌
- 不宜与丁香同用；孕妇慎用
