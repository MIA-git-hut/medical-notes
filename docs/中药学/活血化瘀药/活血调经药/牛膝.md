# 牛膝

> [!info] 速记
> 逐瘀通经、补肝肾为要

## 性味归经
- 性味：苦、甘、酸，平
- 归经：肝、肾经

## 功效
- 逐瘀通经
- 补肝肾
- 强筋骨
- 利尿通淋
- 引血下行

## 主治
- 经闭痛经，产后腹痛，跌打损伤
- 腰膝酸痛，筋骨无力
- 淋证水肿，小便不利
- 头痛眩晕，齿龈肿痛，吐血衄血

## 用法用量
- 煎服，5～12g；活血通经、引血下行宜生用，补肝肾强筋骨宜酒炙

## 禁忌
- 孕妇慎用；梦遗滑精者慎用
