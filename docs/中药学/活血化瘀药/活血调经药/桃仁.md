# 桃仁

> [!info] 速记
> 活血祛瘀、润肠通便为要

## 性味归经
- 性味：苦、甘，平；有小毒
- 归经：心、肝、大肠经

## 功效
- 活血祛瘀
- 润肠通便
- 止咳平喘

## 主治
- 经闭痛经，癥瘕痞块，跌打损伤
- 肠燥便秘
- 肺痈肠痈
- 咳嗽气喘

## 用法用量
- 煎服，5～10g，捣碎

## 禁忌
- 有小毒，孕妇慎用；便溏者慎用
