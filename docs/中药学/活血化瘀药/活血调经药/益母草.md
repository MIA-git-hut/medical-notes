# 益母草

> [!info] 速记
> 活血调经、利尿消肿为要

## 性味归经
- 性味：苦、辛，微寒
- 归经：肝、心包、膀胱经

## 功效
- 活血调经
- 利尿消肿
- 清热解毒

## 主治
- 月经不调，痛经经闭，产后瘀滞腹痛
- 水肿尿少
- 疮疡肿毒

## 用法用量
- 煎服，9～30g；鲜品加倍

## 禁忌
- 孕妇忌用；阴虚血少者慎用
