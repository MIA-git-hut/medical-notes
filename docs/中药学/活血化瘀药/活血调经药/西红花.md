# 西红花

> [!info] 速记
> 活血化瘀、凉血解毒为要

## 性味归经
- 性味：甘，微寒
- 归经：心、肝经

## 功效
- 活血化瘀
- 凉血解毒
- 解郁安神

## 主治
- 经闭癥瘕，产后瘀阻
- 温毒发斑
- 忧郁痞闷，惊悸发狂

## 用法用量
- 煎服（泡服），1～3g

## 禁忌
- 孕妇忌用
