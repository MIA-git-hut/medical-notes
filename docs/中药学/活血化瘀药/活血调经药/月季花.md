# 月季花

> [!info] 速记
> 活血调经、疏肝解郁为要

## 性味归经
- 性味：甘，温
- 归经：肝经

## 功效
- 活血调经
- 疏肝解郁

## 主治
- 月经不调，痛经经闭
- 胸胁胀痛

## 用法用量
- 煎服，3～6g；不宜久煎

## 禁忌
- 孕妇慎用
