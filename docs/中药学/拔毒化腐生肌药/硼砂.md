# 硼砂

> [!info] 速记
> 外用清热解毒，消肿防腐、内服清肺化痰为要

## 性味归经
- 性味：甘、咸，凉
- 归经：肺、胃经

## 功效
- 外用清热解毒，消肿防腐
- 内服清肺化痰

## 主治
- 咽喉肿痛，口舌生疮，目赤翳障（外用）
- 痰热咳嗽（内服）

## 用法用量
- 外用适量，研极细末撒布或调敷；内服入丸散，1.5～3g

## 禁忌
- 内服宜慎，不宜过量；脾虚便溏者慎用
