# 砒石

> [!info] 速记
> 外用攻毒杀虫，蚀疮去腐、内服劫痰平喘，截疟为要

## 性味归经
- 性味：辛，大热；大毒
- 归经：肺、脾、肝经

## 功效
- 外用攻毒杀虫，蚀疮去腐
- 内服劫痰平喘，截疟

## 主治
- 瘰疬，痔疮，牙疳，顽癣（外用）
- 寒痰哮喘（内服）

## 用法用量
- 外用适量，研末撒敷或入膏药；内服入丸散，0.002～0.004g

## 禁忌
- 大毒，内服极须谨慎，孕妇禁用；不可过量久服；忌火煅
