# 炉甘石

> [!info] 速记
> 解毒明目退翳、收湿止痒敛疮为要

## 性味归经
- 性味：甘，平
- 归经：肝、胃经

## 功效
- 解毒明目退翳
- 收湿止痒敛疮

## 主治
- 目赤翳障，目暗不明
- 溃疡不敛，湿疮湿疹，皮肤瘙痒（外用）

## 用法用量
- 外用适量，水飞点眼或研末撒布

## 禁忌
- 专供外用，不作内服
