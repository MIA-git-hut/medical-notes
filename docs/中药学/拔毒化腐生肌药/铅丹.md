# 铅丹

> [!info] 速记
> 外用拔毒生肌，杀虫止痒、内服坠痰镇惊为要

## 性味归经
- 性味：辛、咸，微寒；有毒
- 归经：心、肝经

## 功效
- 外用拔毒生肌，杀虫止痒
- 内服坠痰镇惊

## 主治
- 疮疡溃烂，湿疹瘙痒（外用）
- 惊痫癫狂（内服）

## 用法用量
- 外用适量，研末撒布或熬膏贴敷；内服入丸散，0.3～0.6g

## 禁忌
- 有毒，不可过量久服；孕妇禁用；不宜长期使用
