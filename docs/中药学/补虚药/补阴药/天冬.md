# 天冬

> [!info] 速记
> 养阴润燥、清肺生津为要

## 性味归经
- 性味：甘、苦，寒
- 归经：肺、肾经

## 功效
- 养阴润燥
- 清肺生津

## 主治
- 肺燥干咳，顿咳痰黏，劳嗽咯血
- 肾阴不足，阴虚火旺，潮热盗汗
- 内热消渴，肠燥便秘

## 用法用量
- 煎服，6～12g

## 禁忌
- 脾胃虚寒、食少便溏、外感风寒咳嗽者忌用
