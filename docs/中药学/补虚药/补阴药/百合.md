# 百合

> [!info] 速记
> 养阴润肺、清心安神为要

## 性味归经
- 性味：甘，微寒
- 归经：心、肺经

## 功效
- 养阴润肺
- 清心安神

## 主治
- 阴虚燥咳，劳嗽咯血
- 虚烦惊悸，失眠多梦，精神恍惚

## 用法用量
- 煎服，6～12g；蜜炙可增强润肺

## 禁忌
- 风寒咳嗽、中寒便溏者忌用
