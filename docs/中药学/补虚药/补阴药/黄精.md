# 黄精

> [!info] 速记
> 补气养阴、健脾为要

## 性味归经
- 性味：甘，平
- 归经：脾、肺、肾经

## 功效
- 补气养阴
- 健脾
- 润肺
- 益肾

## 主治
- 脾胃虚弱，体倦乏力，口干食少
- 肺虚燥咳，劳嗽咯血
- 精血不足，腰膝酸软，须发早白，内热消渴

## 用法用量
- 煎服，9～15g

## 禁忌
- 脾虚湿阻、痰湿壅滞、中寒便溏者慎用
