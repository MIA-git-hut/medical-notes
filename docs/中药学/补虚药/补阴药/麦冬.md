# 麦冬

> [!info] 速记
> 养阴生津、润肺清心为要

## 性味归经
- 性味：甘、微苦，微寒
- 归经：心、肺、胃经

## 功效
- 养阴生津
- 润肺清心

## 主治
- 肺燥干咳，阴虚劳嗽，喉痹咽痛
- 胃阴不足，津伤口渴，内热消渴
- 心烦失眠，肠燥便秘

## 用法用量
- 煎服，6～12g

## 禁忌
- 不宜与藜芦同用；风寒咳嗽、脾胃虚寒泄泻者忌用
