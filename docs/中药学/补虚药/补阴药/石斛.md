# 石斛

> [!info] 速记
> 益胃生津、滋阴清热为要

## 性味归经
- 性味：甘，微寒
- 归经：胃、肾经

## 功效
- 益胃生津
- 滋阴清热

## 主治
- 热病津伤，口干烦渴，胃阴不足，食少干呕
- 阴虚火旺，骨蒸劳热，目暗不明，筋骨痿软

## 用法用量
- 煎服，6～12g，鲜品15～30g

## 禁忌
- 温热病早期阴未伤者、湿温未化燥者忌用；脾胃虚寒者慎用
