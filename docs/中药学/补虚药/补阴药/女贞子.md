# 女贞子

> [!info] 速记
> 滋补肝肾、明目乌发为要

## 性味归经
- 性味：甘、苦，凉
- 归经：肝、肾经

## 功效
- 滋补肝肾
- 明目乌发

## 主治
- 肝肾阴虚，眩晕耳鸣，腰膝酸软，须发早白
- 目暗不明，内热消渴，骨蒸潮热

## 用法用量
- 煎服，6～12g

## 禁忌
- 脾胃虚寒泄泻及阳虚者忌用
