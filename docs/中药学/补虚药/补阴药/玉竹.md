# 玉竹

> [!info] 速记
> 养阴润燥、生津止渴为要

## 性味归经
- 性味：甘，微寒
- 归经：肺、胃经

## 功效
- 养阴润燥
- 生津止渴

## 主治
- 肺胃阴伤，燥热咳嗽，咽干口渴
- 内热消渴

## 用法用量
- 煎服，6～12g

## 禁忌
- 脾虚便溏者慎用；痰湿内蕴者不宜
