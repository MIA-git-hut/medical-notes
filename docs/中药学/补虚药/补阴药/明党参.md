# 明党参

> [!info] 速记
> 润肺化痰、养阴和胃为要

## 性味归经
- 性味：甘、微苦，微寒
- 归经：肺、脾、肝经

## 功效
- 润肺化痰
- 养阴和胃
- 平肝
- 解毒

## 主治
- 肺热咳嗽，呕吐反胃
- 食少口干
- 目赤眩晕
- 疔毒疮疡

## 用法用量
- 煎服，6～12g

## 禁忌
- 脾虚泄泻者慎用
