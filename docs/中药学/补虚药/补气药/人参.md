# 人参

> [!info] 速记
> 大补元气、复脉固脱为要

## 性味归经
- 性味：甘、微苦，微温
- 归经：脾、肺、心、肾经

## 功效
- 大补元气
- 复脉固脱
- 补脾益肺
- 生津养血
- 安神益智

## 主治
- 体虚欲脱，肢冷脉微
- 脾虚食少，肺虚喘咳
- 津伤口渴，内热消渴
- 气血亏虚，久病虚羸
- 心悸失眠，阳痿宫冷

## 用法用量
- 煎服，3～9g，另煎兑服；研末吞服，每次2g

## 禁忌
- 不宜与藜芦、五灵脂同用；实证、热证而正气不虚者忌用
