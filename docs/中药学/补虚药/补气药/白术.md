# 白术

> [!info] 速记
> 健脾益气、燥湿利水为要

## 性味归经
- 性味：甘、苦，温
- 归经：脾、胃经

## 功效
- 健脾益气
- 燥湿利水
- 止汗
- 安胎

## 主治
- 脾虚食少，腹胀泄泻
- 痰饮眩悸
- 水肿，小便不利
- 气虚自汗
- 胎动不安

## 用法用量
- 煎服，6～12g；健脾止泻宜炒用，燥湿利水宜生用

## 禁忌
- 阴虚内热、津液亏耗者慎用
