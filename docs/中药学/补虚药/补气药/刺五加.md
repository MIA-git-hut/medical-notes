# 刺五加

> [!info] 速记
> 益气健脾、补肾安神为要

## 性味归经
- 性味：甘、微苦，温
- 归经：脾、肺、心、肾经

## 功效
- 益气健脾
- 补肾安神

## 主治
- 脾肺气虚，体虚乏力，食欲不振
- 肺肾两虚，久咳虚喘
- 肾虚腰膝酸痛，失眠多梦

## 用法用量
- 煎服，9～27g

## 禁忌
- 阴虚火旺者慎用
