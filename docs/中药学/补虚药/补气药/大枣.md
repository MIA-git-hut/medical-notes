# 大枣

> [!info] 速记
> 补中益气、养血安神为要

## 性味归经
- 性味：甘，温
- 归经：脾、胃、心经

## 功效
- 补中益气
- 养血安神

## 主治
- 脾虚食少，乏力便溏
- 妇人脏躁，失眠
- 气血亏虚

## 用法用量
- 煎服，6～15g；劈破煎服

## 禁忌
- 湿盛中满、食积、虫积者慎用
