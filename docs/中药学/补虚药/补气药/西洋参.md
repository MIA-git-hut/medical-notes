# 西洋参

> [!info] 速记
> 补气养阴、清热生津为要

## 性味归经
- 性味：甘、微苦，凉
- 归经：心、肺、肾经

## 功效
- 补气养阴
- 清热生津

## 主治
- 气虚阴亏，虚热烦倦，咳喘痰血
- 内热消渴，口燥咽干

## 用法用量
- 煎服，3～6g，另煎兑服；含化或研粉冲服

## 禁忌
- 不宜与藜芦同用；中阳虚衰、寒湿中阻者忌用
