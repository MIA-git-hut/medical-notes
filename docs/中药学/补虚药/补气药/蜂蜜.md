# 蜂蜜

> [!info] 速记
> 补中、润燥为要

## 性味归经
- 性味：甘，平
- 归经：肺、脾、大肠经

## 功效
- 补中
- 润燥
- 止痛
- 解毒
- 外用生肌敛疮

## 主治
- 脾胃虚弱，脘腹疼痛
- 肺燥干咳，肠燥便秘
- 疮疡不敛（外用）

## 用法用量
- 冲服或入丸膏剂，15～30g；外用适量

## 禁忌
- 湿盛中满、湿热痰滞、便溏泄泻者慎用
