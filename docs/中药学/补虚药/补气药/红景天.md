# 红景天

> [!info] 速记
> 益气活血、通脉平喘为要

## 性味归经
- 性味：甘、苦，平
- 归经：肺、脾、心经

## 功效
- 益气活血
- 通脉平喘

## 主治
- 气虚血瘀之胸痹心痛，中风偏瘫
- 倦怠气喘

## 用法用量
- 煎服，3～6g；研末服，每次2g

## 禁忌
- 无明显禁忌
