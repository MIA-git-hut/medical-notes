# 绞股蓝

> [!info] 速记
> 益气健脾、化痰止咳为要

## 性味归经
- 性味：甘、苦，寒
- 归经：脾、肺经

## 功效
- 益气健脾
- 化痰止咳
- 清热解毒

## 主治
- 脾虚乏力，食欲不振
- 肺虚咳嗽
- 热毒疮疡

## 用法用量
- 煎服，10～20g；研末服，3～6g

## 禁忌
- 脾胃虚寒者慎用
