# 白扁豆

> [!info] 速记
> 健脾化湿、和中消暑为要

## 性味归经
- 性味：甘，微温
- 归经：脾、胃经

## 功效
- 健脾化湿
- 和中消暑

## 主治
- 脾胃虚弱，食欲不振，大便溏泻
- 暑湿吐泻
- 胸闷腹胀

## 用法用量
- 煎服，9～15g；健脾止泻宜炒用

## 禁忌
- 无明显禁忌
