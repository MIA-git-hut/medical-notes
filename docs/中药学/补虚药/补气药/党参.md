# 党参

> [!info] 速记
> 健脾益肺、养血生津为要

## 性味归经
- 性味：甘，平
- 归经：脾、肺经

## 功效
- 健脾益肺
- 养血生津

## 主治
- 脾肺气虚，食少倦怠，咳嗽虚喘
- 气血不足，面色萎黄
- 气津两伤，口渴

## 用法用量
- 煎服，9～30g

## 禁忌
- 不宜与藜芦同用；实热证不宜用
