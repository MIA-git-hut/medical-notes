# 山药

> [!info] 速记
> 补脾养胃、生津益肺为要

## 性味归经
- 性味：甘，平
- 归经：脾、肺、肾经

## 功效
- 补脾养胃
- 生津益肺
- 补肾涩精

## 主治
- 脾虚食少，久泻不止
- 肺虚喘咳
- 肾虚遗精，带下，尿频
- 虚热消渴

## 用法用量
- 煎服，15～30g；麸炒增强补脾止泻

## 禁忌
- 湿盛中满或有积滞者慎用
