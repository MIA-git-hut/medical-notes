# 仙茅

> [!info] 速记
> 补肾阳、强筋骨为要

## 性味归经
- 性味：辛，热；有毒
- 归经：肾、肝、脾经

## 功效
- 补肾阳
- 强筋骨
- 祛寒湿

## 主治
- 肾阳不足，阳痿精冷，小便失禁
- 腰膝冷痛，筋骨痿软
- 寒湿痹痛

## 用法用量
- 煎服，3～10g

## 禁忌
- 有毒，不宜久服；阴虚火旺者忌用
