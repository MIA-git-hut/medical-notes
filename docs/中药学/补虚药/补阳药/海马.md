# 海马

> [!info] 速记
> 温肾壮阳、散结消肿为要

## 性味归经
- 性味：甘、咸，温
- 归经：肝、肾经

## 功效
- 温肾壮阳
- 散结消肿

## 主治
- 肾阳不足，阳痿遗精，遗尿
- 癥瘕积聚，跌打损伤
- 疔疮肿毒

## 用法用量
- 煎服，3～9g；研末服，每次1～1.5g

## 禁忌
- 孕妇及阴虚火旺者忌用
