# 鹿茸

> [!info] 速记
> 壮肾阳、益精血为要

## 性味归经
- 性味：甘、咸，温
- 归经：肾、肝经

## 功效
- 壮肾阳
- 益精血
- 强筋骨
- 调冲任
- 托疮毒

## 主治
- 肾阳不足，精血亏虚，阳痿滑精，宫冷不孕，羸瘦神疲，畏寒眩晕
- 筋骨痿软，小儿五迟
- 冲任虚寒，崩漏带下
- 阴疽内陷不起

## 用法用量
- 研末冲服，1～2g，或入丸散

## 禁忌
- 阴虚阳亢、血热、胃火盛、肺有痰热及外感热病者忌用；服用宜从小剂量开始
