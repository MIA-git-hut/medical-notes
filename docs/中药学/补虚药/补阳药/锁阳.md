# 锁阳

> [!info] 速记
> 补肾阳、益精血为要

## 性味归经
- 性味：甘，温
- 归经：肝、肾、大肠经

## 功效
- 补肾阳
- 益精血
- 润肠通便

## 主治
- 肾阳不足，精血亏虚，腰膝痿软，阳痿滑精
- 肠燥便秘

## 用法用量
- 煎服，5～10g

## 禁忌
- 阴虚火旺、脾虚泄泻及实热便秘者忌用
