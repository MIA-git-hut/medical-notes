# 肉苁蓉

> [!info] 速记
> 补肾阳、益精血为要

## 性味归经
- 性味：甘、咸，温
- 归经：肾、大肠经

## 功效
- 补肾阳
- 益精血
- 润肠通便

## 主治
- 肾阳不足，精血亏虚，阳痿不孕，腰膝酸软，筋骨无力
- 肠燥便秘

## 用法用量
- 煎服，6～10g

## 禁忌
- 阴虚火旺、便溏泄泻者忌用；肠胃实热便秘者不宜
