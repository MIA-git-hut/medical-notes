# 补骨脂

> [!info] 速记
> 补肾壮阳、固精缩尿为要

## 性味归经
- 性味：辛、苦，温
- 归经：肾、脾经

## 功效
- 补肾壮阳
- 固精缩尿
- 温脾止泻
- 纳气平喘

## 主治
- 肾阳不足，腰膝冷痛，阳痿遗精，遗尿尿频
- 脾肾阳虚，五更泄泻
- 肾不纳气，虚寒喘咳

## 用法用量
- 煎服，6～10g；外用适量

## 禁忌
- 阴虚火旺者忌用；大剂量可致光敏反应
