# 菟丝子

> [!info] 速记
> 补益肝肾、固精缩尿为要

## 性味归经
- 性味：甘，温
- 归经：肝、肾、脾经

## 功效
- 补益肝肾
- 固精缩尿
- 安胎
- 明目
- 止泻
- 外用消风祛斑

## 主治
- 肝肾不足，腰膝酸软，阳痿遗精，遗尿尿频
- 肾虚胎漏，胎动不安
- 目昏耳鸣
- 脾肾虚泻
- 白癜风（外用）

## 用法用量
- 煎服，6～12g；外用适量

## 禁忌
- 阴虚火旺、大便燥结者慎用
