# 沙苑子

> [!info] 速记
> 补肾助阳、固精缩尿为要

## 性味归经
- 性味：甘，温
- 归经：肝、肾经

## 功效
- 补肾助阳
- 固精缩尿
- 养肝明目

## 主治
- 肾虚腰痛，遗精早泄，遗尿尿频
- 肝肾不足，目暗昏花

## 用法用量
- 煎服，9～15g

## 禁忌
- 阴虚火旺及小便不利者慎用
