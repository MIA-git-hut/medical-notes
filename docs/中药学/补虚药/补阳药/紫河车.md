# 紫河车

> [!info] 速记
> 温肾补精、益气养血为要

## 性味归经
- 性味：甘、咸，温
- 归经：肺、肝、肾经

## 功效
- 温肾补精
- 益气养血

## 主治
- 虚劳羸瘦，骨蒸盗汗，咳嗽气喘
- 阳痿遗精，不孕少乳
- 气血亏虚，面色萎黄

## 用法用量
- 研末装胶囊服，2～3g；或鲜品炖食

## 禁忌
- 阴虚火旺者不宜单用；有实邪者慎用
