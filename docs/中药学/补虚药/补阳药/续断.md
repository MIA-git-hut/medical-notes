# 续断

> [!info] 速记
> 补肝肾、强筋骨为要

## 性味归经
- 性味：苦、辛，微温
- 归经：肝、肾经

## 功效
- 补肝肾
- 强筋骨
- 续折伤
- 止崩漏

## 主治
- 腰膝酸软，风湿痹痛
- 跌打损伤，筋伤骨折
- 崩漏经多，胎漏下血，胎动不安

## 用法用量
- 煎服，9～15g；酒炙增强通脉之力

## 禁忌
- 风湿热痹者慎用
