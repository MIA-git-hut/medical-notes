# 益智仁

> [!info] 速记
> 暖肾固精缩尿、温脾止泻摄唾为要

## 性味归经
- 性味：辛，温
- 归经：肾、脾经

## 功效
- 暖肾固精缩尿
- 温脾止泻摄唾

## 主治
- 肾虚遗尿，小便频数，遗精白浊
- 脾寒泄泻，腹中冷痛，口多唾涎

## 用法用量
- 煎服，3～10g

## 禁忌
- 阴虚火旺、湿热者忌用
