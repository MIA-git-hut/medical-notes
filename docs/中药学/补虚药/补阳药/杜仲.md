# 杜仲

> [!info] 速记
> 补肝肾、强筋骨为要

## 性味归经
- 性味：甘，温
- 归经：肝、肾经

## 功效
- 补肝肾
- 强筋骨
- 安胎

## 主治
- 肾虚腰痛，筋骨无力
- 妊娠漏血，胎动不安
- 高血压属肝肾不足者

## 用法用量
- 煎服，6～10g；盐炙增强补肝肾

## 禁忌
- 阴虚火旺者慎用
