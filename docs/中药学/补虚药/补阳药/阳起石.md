# 阳起石

> [!info] 速记
> 温肾壮阳为要

## 性味归经
- 性味：咸，温
- 归经：肾经

## 功效
- 温肾壮阳

## 主治
- 阳痿不举，宫冷不孕，腰膝冷痹

## 用法用量
- 入丸散，3～6g；不入煎剂

## 禁忌
- 阴虚火旺者忌用
