# 核桃仁

> [!info] 速记
> 补肾温肺、润肠通便为要

## 性味归经
- 性味：甘，温
- 归经：肾、肺、大肠经

## 功效
- 补肾温肺
- 润肠通便

## 主治
- 肾虚腰痛，脚膝痿弱，遗精遗尿
- 肺虚久咳气喘
- 肠燥便秘

## 用法用量
- 煎服，6～9g；嚼服或入丸散

## 禁忌
- 阴虚火旺、痰火咳嗽、便溏者慎用
