# 淫羊藿

> [!info] 速记
> 补肾阳、强筋骨为要

## 性味归经
- 性味：辛、甘，温
- 归经：肾、肝经

## 功效
- 补肾阳
- 强筋骨
- 祛风湿

## 主治
- 肾阳虚衰，阳痿遗精，筋骨痿软
- 风湿痹痛，麻木拘挛

## 用法用量
- 煎服，6～10g

## 禁忌
- 阴虚火旺者忌用
