# 白芍

> [!info] 速记
> 养血调经、敛阴止汗为要

## 性味归经
- 性味：苦、酸，微寒
- 归经：肝、脾经

## 功效
- 养血调经
- 敛阴止汗
- 柔肝止痛
- 平抑肝阳

## 主治
- 血虚萎黄，月经不调，痛经崩漏
- 自汗盗汗
- 肝郁胁痛，脘腹疼痛，四肢挛急疼痛
- 肝阳上亢，头痛眩晕

## 用法用量
- 煎服，6～15g；大剂量15～30g

## 禁忌
- 不宜与藜芦同用；阳衰虚寒之证不宜单独使用
