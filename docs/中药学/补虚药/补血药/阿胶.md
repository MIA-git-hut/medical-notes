# 阿胶

> [!info] 速记
> 补血滋阴、润燥为要

## 性味归经
- 性味：甘，平
- 归经：肺、肝、肾经

## 功效
- 补血滋阴
- 润燥
- 止血

## 主治
- 血虚萎黄，眩晕心悸，肌痿无力
- 热病伤阴，心烦不眠，虚风内动
- 肺燥咳嗽，劳嗽咯血
- 吐血衄血，便血崩漏

## 用法用量
- 烊化兑服，3～9g；入丸散用

## 禁忌
- 脾胃虚弱、消化不良者慎用
