# 当归

> [!info] 速记
> 补血活血、调经止痛为要

## 性味归经
- 性味：甘、辛，温
- 归经：肝、心、脾经

## 功效
- 补血活血
- 调经止痛
- 润肠通便

## 主治
- 血虚萎黄，眩晕心悸
- 月经不调，经闭痛经
- 虚寒腹痛，风湿痹痛，跌打损伤
- 痈疽疮疡
- 肠燥便秘

## 用法用量
- 煎服，6～12g；补血用当归身，活血用当归尾，和血用全当归

## 禁忌
- 湿盛中满、大便溏泄者慎用
