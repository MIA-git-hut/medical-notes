# 熟地黄

> [!info] 速记
> 补血滋阴、益精填髓为要

## 性味归经
- 性味：甘，微温
- 归经：肝、肾经

## 功效
- 补血滋阴
- 益精填髓

## 主治
- 血虚萎黄，心悸怔忡，月经不调，崩漏下血
- 肝肾阴虚，腰膝酸软，骨蒸潮热，盗汗遗精，内热消渴
- 精血亏虚，须发早白，眩晕耳鸣

## 用法用量
- 煎服，9～15g

## 禁忌
- 脾胃虚弱、气滞痰多、腹满便溏者慎用
