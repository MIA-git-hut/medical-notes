# 何首乌

> [!info] 速记
> 补肝肾、益精血为要

## 性味归经
- 性味：苦、甘、涩，微温（制）
- 归经：肝、心、肾经

## 功效
- 补肝肾
- 益精血
- 乌须发
- 强筋骨
- 化浊降脂

## 主治
- 血虚萎黄，眩晕耳鸣，须发早白，腰膝酸软，肢体麻木
- 崩漏带下
- 高脂血症

## 用法用量
- 煎服，6～12g（制用）

## 禁忌
- 湿痰较重、大便溏泄者慎用；生首乌有毒，忌铁器煎煮
