# 榧子

> [!info] 速记
> 杀虫消积、润肠通便为要

## 性味归经
- 性味：甘，平
- 归经：肺、胃、大肠经

## 功效
- 杀虫消积
- 润肠通便
- 润肺止咳

## 主治
- 虫积腹痛
- 肠燥便秘
- 肺燥咳嗽

## 用法用量
- 炒熟嚼服，9～15g

## 禁忌
- 大便溏薄、肺热咳嗽者慎用
