# 槟榔

> [!info] 速记
> 杀虫、消积为要

## 性味归经
- 性味：苦、辛，温
- 归经：胃、大肠经

## 功效
- 杀虫
- 消积
- 行气
- 利水
- 截疟

## 主治
- 绦虫病，蛔虫病，姜片虫病，虫积腹痛
- 食积气滞，泻痢后重
- 水肿，脚气肿痛
- 疟疾

## 用法用量
- 煎服，3～10g；驱绦虫、姜片虫30～60g

## 禁忌
- 脾虚便溏者慎用；孕妇慎用
