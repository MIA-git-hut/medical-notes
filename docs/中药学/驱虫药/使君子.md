# 使君子

> [!info] 速记
> 杀虫消积为要

## 性味归经
- 性味：甘，温
- 归经：脾、胃经

## 功效
- 杀虫消积

## 主治
- 蛔虫病，蛲虫病，虫积腹痛
- 小儿疳积

## 用法用量
- 煎服，9～12g，捣碎；取仁炒香嚼服，6～9g；小儿每岁1～1.5粒，总量不超过20粒

## 禁忌
- 大量服用可致呃逆、眩晕；忌与热茶同服
