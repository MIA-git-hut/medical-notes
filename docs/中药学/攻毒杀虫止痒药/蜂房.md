# 蜂房

> [!info] 速记
> 攻毒杀虫、祛风止痛为要

## 性味归经
- 性味：甘，平；有毒
- 归经：胃经

## 功效
- 攻毒杀虫
- 祛风止痛

## 主治
- 疮疡肿毒，乳痈，瘰疬，顽癣瘙痒
- 风湿痹痛，牙痛

## 用法用量
- 煎服，3～5g；外用适量，研末油调敷

## 禁忌
- 有毒，气血虚弱者慎用；肾功能不全者忌用
