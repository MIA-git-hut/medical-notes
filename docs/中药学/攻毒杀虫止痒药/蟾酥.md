# 蟾酥

> [!info] 速记
> 解毒、止痛为要

## 性味归经
- 性味：辛，温；有毒
- 归经：心经

## 功效
- 解毒
- 止痛
- 开窍醒神

## 主治
- 痈疽疔疮，咽喉肿痛，龋齿疼痛
- 中暑昏厥，吐泻腹痛

## 用法用量
- 入丸散，0.015～0.03g；外用适量

## 禁忌
- 有毒，内服切勿过量；孕妇禁用；外用不可入目
