# 樟脑

> [!info] 速记
> 除湿杀虫、温散止痛为要

## 性味归经
- 性味：辛，热；有毒
- 归经：心、脾经

## 功效
- 除湿杀虫
- 温散止痛
- 开窍辟秽

## 主治
- 疥癣瘙痒，湿疮溃烂（外用）
- 跌打伤痛，牙痛（外用）
- 痧胀腹痛，吐泻神昏

## 用法用量
- 外用适量；内服入丸散，0.1～0.2g

## 禁忌
- 有毒，内服宜慎，孕妇禁用；气虚者忌服
