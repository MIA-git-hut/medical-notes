# 雄黄

> [!info] 速记
> 解毒杀虫、燥湿祛痰为要

## 性味归经
- 性味：辛，温；有毒
- 归经：肝、大肠经

## 功效
- 解毒杀虫
- 燥湿祛痰
- 截疟

## 主治
- 痈肿疔疮，蛇虫咬伤
- 虫积腹痛
- 疥癣
- 疟疾
- 哮喘

## 用法用量
- 入丸散，0.05～0.1g；外用适量，熏涂患处

## 禁忌
- 有毒，内服宜慎，不可过量久服；孕妇禁用；忌火煅
