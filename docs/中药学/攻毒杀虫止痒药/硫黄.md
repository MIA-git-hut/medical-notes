# 硫黄

> [!info] 速记
> 外用解毒杀虫疗疮、内服补火助阳通便为要

## 性味归经
- 性味：酸，温；有毒
- 归经：肾、大肠经

## 功效
- 外用解毒杀虫疗疮
- 内服补火助阳通便

## 主治
- 疥癣，秃疮，阴疽恶疮（外用）
- 阳痿足冷，虚喘冷哮，虚寒便秘（内服）

## 用法用量
- 外用适量，研末油调涂敷；内服入丸散，1.5～3g，炮制后服

## 禁忌
- 有毒，孕妇禁用；阴虚火旺者忌用；不宜与朴硝同用
