# 白矾

> [!info] 速记
> 外用解毒杀虫，燥湿止痒、内服止血止泻，祛除风痰为要

## 性味归经
- 性味：酸、涩，寒
- 归经：肺、脾、肝、大肠经

## 功效
- 外用解毒杀虫，燥湿止痒
- 内服止血止泻，祛除风痰

## 主治
- 湿疹瘙痒，疥癣（外用）
- 便血崩漏，久泻久痢
- 癫痫发狂

## 用法用量
- 内服入丸散，0.6～1.5g；外用适量

## 禁忌
- 体虚胃弱、无湿热痰火者忌用；不宜过量久服
