# 蛇床子

> [!info] 速记
> 燥湿祛风、杀虫止痒为要

## 性味归经
- 性味：辛、苦，温；有小毒
- 归经：肾经

## 功效
- 燥湿祛风
- 杀虫止痒
- 温肾壮阳

## 主治
- 阴痒带下，湿疹疥癣（外用）
- 肾虚阳痿，宫冷不孕
- 寒湿带下，湿痹腰痛

## 用法用量
- 煎服，3～10g；外用适量，煎汤熏洗或研末调敷

## 禁忌
- 有小毒，阴虚火旺或下焦有湿热者不宜内服
