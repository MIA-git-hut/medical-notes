# 大蒜

> [!info] 速记
> 解毒杀虫、消肿为要

## 性味归经
- 性味：辛，温
- 归经：脾、胃、肺经

## 功效
- 解毒杀虫
- 消肿
- 止痢

## 主治
- 痈肿疮毒，疥癣（外用）
- 痢疾泄泻，肺痨咳嗽
- 钩虫、蛲虫病

## 用法用量
- 生食、绞汁服或煎服，6～12g；外用适量

## 禁忌
- 阴虚火旺、目疾、口齿病者慎用；不宜空腹生食
