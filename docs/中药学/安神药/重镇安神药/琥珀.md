# 琥珀

> [!info] 速记
> 镇惊安神、活血散瘀为要

## 性味归经
- 性味：甘，平
- 归经：心、肝、膀胱经

## 功效
- 镇惊安神
- 活血散瘀
- 利尿通淋

## 主治
- 心神不宁，心悸失眠，惊风癫痫
- 血滞经闭，癥瘕
- 淋证尿血，小便不利

## 用法用量
- 研末冲服或入丸散，1.5～3g；不入煎剂

## 禁忌
- 阴虚内热、津液不足者慎用
