# 朱砂

> [!info] 速记
> 清心镇惊、安神为要

## 性味归经
- 性味：甘，微寒；有毒
- 归经：心经

## 功效
- 清心镇惊
- 安神
- 明目
- 解毒

## 主治
- 心神不宁，心悸失眠
- 惊风癫痫
- 疮疡肿毒，咽喉肿痛

## 用法用量
- 研末冲服或入丸散，0.1～0.5g；不宜入煎剂

## 禁忌
- 有毒，不可过量久服；忌火煅；孕妇及肝肾功能不全者禁用
