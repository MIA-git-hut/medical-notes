# 龙骨

> [!info] 速记
> 镇惊安神、平肝潜阳为要

## 性味归经
- 性味：甘、涩，平
- 归经：心、肝、肾经

## 功效
- 镇惊安神
- 平肝潜阳
- 收敛固涩

## 主治
- 心神不宁，心悸失眠，惊痫癫狂
- 肝阳眩晕
- 滑脱诸证（自汗盗汗、遗精、崩漏、带下）

## 用法用量
- 煎服，15～30g，先煎；收敛固涩宜煅用

## 禁忌
- 湿热积滞者慎用
