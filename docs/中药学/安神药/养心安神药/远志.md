# 远志

> [!info] 速记
> 安神益智、交通心肾为要

## 性味归经
- 性味：苦、辛，温
- 归经：心、肾、肺经

## 功效
- 安神益智
- 交通心肾
- 祛痰
- 消肿

## 主治
- 心肾不交之失眠健忘，惊悸
- 痰阻心窍之癫痫发狂
- 咳嗽痰多
- 痈疽疮毒（外用）

## 用法用量
- 煎服，3～10g；外用适量；甘草水炙可缓和刺激

## 禁忌
- 胃炎及胃溃疡者慎用
