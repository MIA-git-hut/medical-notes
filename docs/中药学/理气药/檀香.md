# 檀香

> [!info] 速记
> 行气温中、开胃止痛为要

## 性味归经
- 性味：辛，温
- 归经：脾、胃、心、肺经

## 功效
- 行气温中
- 开胃止痛

## 主治
- 寒凝气滞，胸膈不舒，脘腹疼痛
- 心腹疼痛

## 用法用量
- 煎服，2～5g，后下

## 禁忌
- 阴虚火旺者慎用
