# 川楝子

> [!info] 速记
> 疏肝泄热、行气止痛为要

## 性味归经
- 性味：苦，寒；有小毒
- 归经：肝、小肠、膀胱经

## 功效
- 疏肝泄热
- 行气止痛
- 杀虫

## 主治
- 肝郁化火，胸胁脘腹胀痛，疝气疼痛
- 虫积腹痛

## 用法用量
- 煎服，3～10g

## 禁忌
- 有小毒，不宜过量或久服；脾胃虚寒者慎用
