# 九香虫

> [!info] 速记
> 理气止痛、温中助阳为要

## 性味归经
- 性味：咸，温
- 归经：肝、脾、肾经

## 功效
- 理气止痛
- 温中助阳

## 主治
- 胸胁胀痛，肝胃气痛
- 肾阳不足，腰膝酸软，阳痿

## 用法用量
- 煎服，3～9g

## 禁忌
- 阴虚阳亢者慎用
