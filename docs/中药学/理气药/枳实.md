# 枳实

> [!info] 速记
> 破气消积、化痰散痞为要

## 性味归经
- 性味：苦、辛、酸，微寒
- 归经：脾、胃经

## 功效
- 破气消积
- 化痰散痞

## 主治
- 积滞内停，痞满胀痛，泻痢后重，大便不通
- 痰滞气阻，胸痹结胸
- 胃下垂、子宫脱垂、脱肛

## 用法用量
- 煎服，3～10g

## 禁忌
- 孕妇慎用
