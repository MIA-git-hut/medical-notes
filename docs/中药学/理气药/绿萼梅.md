# 绿萼梅

> 别名：梅花

> [!info] 速记
> 疏肝和中、化痰散结为要

## 性味归经
- 性味：微酸、涩，平
- 归经：肝、胃、肺经

## 功效
- 疏肝和中
- 化痰散结

## 主治
- 肝胃气痛，胸闷胁胀
- 梅核气

## 用法用量
- 煎服，3～6g

## 禁忌
- 无明显禁忌
