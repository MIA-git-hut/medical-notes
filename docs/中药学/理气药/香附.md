# 香附

> [!info] 速记
> 疏肝解郁、理气宽中为要

## 性味归经
- 性味：辛、微苦、微甘，平
- 归经：肝、脾、三焦经

## 功效
- 疏肝解郁
- 理气宽中
- 调经止痛

## 主治
- 肝郁气滞，胸胁胀痛，疝气疼痛，乳房胀痛
- 月经不调，经闭痛经
- 脾胃气滞，脘腹痞闷

## 用法用量
- 煎服，6～10g

## 禁忌
- 气虚无滞、阴虚血热者慎用
