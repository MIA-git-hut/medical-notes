# 木香

> [!info] 速记
> 行气止痛、健脾消食为要

## 性味归经
- 性味：辛、苦，温
- 归经：脾、胃、大肠、三焦、胆经

## 功效
- 行气止痛
- 健脾消食

## 主治
- 胸胁脘腹胀痛，泻痢后重
- 食积不消，不思饮食

## 用法用量
- 煎服，3～6g；生用行气力强，煨用止泻

## 禁忌
- 阴虚津亏、火旺者慎用
