# 乌药

> [!info] 速记
> 行气止痛、温肾散寒为要

## 性味归经
- 性味：辛，温
- 归经：肺、脾、肾、膀胱经

## 功效
- 行气止痛
- 温肾散寒

## 主治
- 寒凝气滞，胸腹胀痛，疝气疼痛，痛经
- 膀胱虚冷，遗尿尿频

## 用法用量
- 煎服，3～10g

## 禁忌
- 气虚及内热者慎用
