# 陈皮

> [!info] 速记
> 理气健脾、燥湿化痰为要

## 性味归经
- 性味：苦、辛，温
- 归经：肺、脾经

## 功效
- 理气健脾
- 燥湿化痰

## 主治
- 脘腹胀满，食少吐泻
- 咳嗽痰多

## 用法用量
- 煎服，3～10g

## 禁忌
- 气虚证、阴虚燥咳、吐血者慎用
