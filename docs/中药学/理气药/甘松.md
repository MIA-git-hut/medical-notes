# 甘松

> [!info] 速记
> 理气止痛、开郁醒脾为要

## 性味归经
- 性味：辛、甘，温
- 归经：脾、胃经

## 功效
- 理气止痛
- 开郁醒脾
- 外用祛湿消肿

## 主治
- 脘腹胀满疼痛
- 思虑伤脾，不思饮食
- 湿脚气

## 用法用量
- 煎服，3～6g；外用适量

## 禁忌
- 气虚血热者忌用
