# 玫瑰花

> [!info] 速记
> 行气解郁、活血止痛为要

## 性味归经
- 性味：甘、微苦，温
- 归经：肝、脾经

## 功效
- 行气解郁
- 活血止痛

## 主治
- 肝胃气痛，食少呕恶
- 月经不调，经前乳房胀痛
- 跌打伤痛

## 用法用量
- 煎服，3～6g

## 禁忌
- 阴虚火旺者慎用
