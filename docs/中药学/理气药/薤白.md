# 薤白

> [!info] 速记
> 通阳散结、行气导滞为要

## 性味归经
- 性味：辛、苦，温
- 归经：心、肺、胃、大肠经

## 功效
- 通阳散结
- 行气导滞

## 主治
- 胸痹心痛，脘腹痞满胀痛
- 泻痢后重

## 用法用量
- 煎服，5～10g

## 禁忌
- 气虚无滞、胃弱纳呆者不宜用
