# 金匮要略

> [!note] 本页为**目录级框架**：完整呈现篇目结构，原文与选读内容按需逐步补充。

> 篇名小注：「脉证并治／脉证治」的「并」字底本与各整理本互有出入（底本多作「脈證並治」），本表按通行整理本写法。第 19 篇底本作「跗蹶手指臂腫轉筋陰狐疝蚘蟲病」（趺蹶/跗蹶互见）。

## 结构说明

- 第 1 篇（脏腑经络先后病）为全书**总论**，论病因、病机、诊法与治则
- 第 2～19 篇为内科杂病各论（痉湿暍、疟病、中风历节、虚劳、痰饮、水气、黄疸等）
- 第 20～22 篇论妇人妊娠、产后与杂病
- 第 23～25 篇（杂疗方、禽兽鱼虫禁忌、果实菜谷禁忌）通常视为**卷末附篇**：内容为急救杂方与饮食禁忌，体例与前面「辨病脉证并治」不同
  - 真伪之争：尤怡、吴谦等疑为后人所附；丹波元简疑为《汉书·艺文志》食禁遗文；李克光等主张为仲景所作。**公认杂有后人附益成分，但不等于全属伪作**
