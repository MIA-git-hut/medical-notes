# 黄帝内经

> [!note] 本页为**目录级框架**：完整呈现篇目结构，原文与选读内容按需逐步补充。

《黄帝内经》分《素问》《灵枢》两部，各 81 篇，是中医理论体系的奠基之作，约成书于战国至秦汉之间，非一时一人之作。

- **素问**：侧重阴阳五行、藏象、诊法、治则、运气等基本理论
- **灵枢**：又称《针经》，侧重经络腧穴、针刺手法与刺禁等
