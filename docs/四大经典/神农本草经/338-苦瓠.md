# 苦瓠

> [!note] 本页为《神农本草经》下经（果菜部下品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味苦，性寒，有毒
- 主治：苦瓠主治水肿，利小便，通淋，治疮
- 用量：普通二至三钱，大剂无定量
- 禁忌：服苦瓠过分吐利不止者，以黍穰灰汁解之

## 原文

> 味苦寒。主治大水面目四肢浮肿，下水。令人吐。生山泽。
