# 鼠妇

> [!note] 本页为《神农本草经》下经（虫兽部下品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味酸，性温，无毒
- 主治：主治气癃不得小便，妇人月闭血瘕，痫痓寒热，利水道
- 用量：普通钱许
- 禁忌：孕妇忌之

## 原文

> 味酸温。主治气癃不得小便，妇人月闭血瘕，痫痓寒热，利水道。一名蟠贞，一名伊咸。生平谷。
