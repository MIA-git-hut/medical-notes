# 鳖甲

> [!note] 本页为《神农本草经》中经（虫兽部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味咸，性平，无毒
- 主治：鳖甲为益阴除热散结要药，主心腹症瘕坚积寒热，治老疟疟母，骨节间劳热，消肿下瘀，能堕胎
- 用量：普通二钱至四钱
- 禁忌：妊娠及阴虚胃弱，阴虚泄泻，产后泄泻，产后饮食不消，不思食及呕恶等证均忌

## 原文

> 味咸平。主治心腹症瘕，坚积寒热，去痞、息肉，阴蚀，痔，恶肉。生池泽。
