# 海藻

> [!note] 本页为《神农本草经》中经（草部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味咸，性寒，无毒
- 主治：海藻为除热软坚要药，主瘿瘤瘰疬，治瘫肿老痰，通血脉，利小便
- 用量：普通一钱至三钱
- 禁忌：脾家有湿者忌

## 原文

> 味苦寒。主治瘿瘤气，颈下核，破散结气，痈肿，症瘕坚气，腹中上下鸣，下十二水肿。一名落首。生池泽。
