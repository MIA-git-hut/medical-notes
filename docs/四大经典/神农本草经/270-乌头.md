# 乌头

> [!note] 本页为《神农本草经》下经（草部下品）药物，原文据通行辑本文字转写简体；「解说」摘自倪海厦《人纪·神农本草经》讲座讲义（含其诵记原文与后世注文），供对照学习。

## 学习要点

- 性味：味辛温有毒
- 主治：主治中风恶风洗洗，出汗，除寒湿痹，咳逆上气，破积聚寒热

## 原文

> 味辛温有毒。主治中风恶风洗洗，出汗，除寒湿痹，咳逆上气，破积聚寒热。其汁煎之，名射罔，杀禽兽。一名奚毒，一名即子，一名乌喙。生山谷。

- "我们经方就是这样子，怎么办？就是...
