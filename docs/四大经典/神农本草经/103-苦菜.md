# 苦菜

> [!note] 本页为《神农本草经》上经（果菜部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味苦，性寒，无毒
- 主治：苦菜主明目，除热，治痈疮，黄疸，调经脉，去邪气
- 用量：普通二至三钱
- 禁忌：脾胃虚寒人不可食，不可共蜜食

## 原文

> 味苦寒。主治五藏邪气，厌榖胃痹。久服安心益气，聪察少卧，轻身耐老。一名荼草，一名选。生川谷。
