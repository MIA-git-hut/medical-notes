# 神农本草经

> [!note] 本页为**目录级框架**：完整呈现结构，原文与选读内容按需逐步补充。

《神农本草经》（简称《本经》）约成书于东汉，托名神农，是现存最早的药物学专著。原书早佚，赖梁·陶弘景《本草经集注》以朱书《本经》原文、墨书《名医别录》增附的方式转录而保存（《集注》合《本经》365 味与《别录》365 味，共 730 味），后世《新修本草》《证类本草》及各种辑复本皆源此传本。

今通行辑复本：明·卢复《神农本经》（1616，现存最早辑本）、清·孙星衍辑本（1799，三卷，附「诸药制使篇」）、清·顾观光辑本（1844，四卷，三品药数与 365 相合）、日本·森立之辑本（1854，四卷并《考异》，校勘最密）、尚志钧《神农本草经校点》（1981）等。

## 三品分类

全载药 365 味，按上、中、下三品为纲：

| 品 | 药数 | 主旨 |
| --- | --- | --- |
| 上品 | 120 | 养命，无毒，多服久服不伤人 |
| 中品 | 120 | 养性，无毒有毒，斟酌其宜 |
| 下品 | 125 | 治病，多毒，不可久服 |
| 合计 | 365 | 「法三百六十五度，一度应一日」 |

药数直接见于序录原文（「上藥一百二十種為君……中藥一百二十種為臣……下藥一百二十五種為佐使」）。另通行统计植物药 252、动物药 67、矿物药 46（合 365）——此系**据顾观光辑本口径**，各辑本收药归类互有出入（如孙星衍本实辑 358 味、森立之本 357 味）。

## 序录要点

- **七情合和**：「有單行者，有相須者，有（相）使者，有相畏者，有相惡者，有相反者，有相殺者。凡此七情和合視之，當用相須相使良者，勿用相惡相反者。若有毒宜制，可用相畏相殺者。」
- **四气五味**：「藥有酸鹹甘苦辛五味，又有寒熱溫涼四氣及有毒無毒。」
- **君臣佐使**：「藥有君臣佐使，以相宣攝合和者，宜用一君二臣五佐，又可一君三臣九佐使也。」
- 剂型宜忌（丸散汤酒膏煎）、毒药「先起如黍粟，病去即止」、治寒以热/治热以寒、服药先后时辰等

## 分部排列

《本经》原书**只有上、中、下三品分类，没有自然属性分类**。「玉石、草、木、人、兽、禽、虫鱼、果、米谷、菜」十类体系源自陶弘景《本草经集注》，经唐《新修本草》扩充，至宋《证类本草》定型。

因原书早佚，今传辑本与整理本编排不一：或沿用十类框架编次三品药物，或因辑本而异（如部分整理本分「玉石部／草部／木部／果菜部／米谷部／虫兽部」六部）。故「《本经》分十类」的流行说法不确，宜表述为「后世辑本常按部类编次」。
