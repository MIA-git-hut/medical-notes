# 贝母

> [!note] 本页为《神农本草经》中经（草部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味辛苦，性平无毒
- 主治：贝母为袪痰治咳要药，功能散结泄热，润肺清火，治烦热疮疡
- 用量：普通钱半至三钱
- 禁忌：寒湿痰食痰嗽，湿痰在胃，恶心欲吐，痰饮作寒热，脾胃湿痰作眩，及痰厥头痛，中恶呕吐，胃寒作泄，法宜用辛温燥热者，均忌贝母

## 原文

> 味辛平。主治伤寒烦热，淋沥、邪气、疝瘕，喉痹，乳难。金疮风痉。一名空草。
