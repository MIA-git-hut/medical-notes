# 石斛

> [!note] 本页为《神农本草经》上经（草部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味甘性平无毒
- 主治：石斛为除热益阴要药，主养脾胃，益心肾，补虚劳，退虚热，治自汗盗汗，小便余沥，脚痛痹弱
- 用量：普通一钱至三钱
- 禁忌：多服能寒胃，至大便溏薄，入姜一二片为辅，则无此弊，清肺补脾也，恶凝水石巴豆，畏雷丸僵蚕

## 原文

> 味甘平。主治伤中，除痹下气，补五脏虚劳羸瘦，强阴。久服厚肠胃，轻身延年。一名林兰。生山谷。
