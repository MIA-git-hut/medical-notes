# 泽漆

> [!note] 本页为《神农本草经》下经（草部下品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味苦，性微寒，无毒（或作小毒）
- 主治：泽漆主治水肿脚肿，消痰退热，敷之消疣
- 用量：普通五分至钱半
- 禁忌：赤小豆为使，恶薯蓣

## 原文

> 味苦微寒。主治皮肤热，大腹水气，四肢面目浮肿，丈夫阴气不足。生川泽。
