# 天门冬

> [!note] 本页为《神农本草经》上经（草部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：见原文
- 主治：为清虚热润燥痰要药，主肺气咳逆，风湿偏痹益肌肤，保肺气治消渴、疗咳血
- 用量：普通一钱至三钱
- 禁忌：胃虚无热及泻者均忌，忌鲤鱼

## 原文

> 味苦平，主治诸暴风湿偏痹，强骨随，杀三虫，去伏尸。久服轻身益气延年。一名颠勒。生山谷。
