# 松脂

> [!note] 本页为《神农本草经》上经（木部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：松脂味苦甘，性温。松子味甘，性微温。松花味甘，性温。松节味苦，性温
- 主治：松脂为袪风寒湿，止痛，生肌，杀虫药；治痈疽恶疮，风痹，死肌，疥癣，蛀齿。松子为祛风，滋润强壮药；治骨节风痹，气虚头眩，肺燥咳嗽，及老人虚闭。松花为驱风，镇静药；治头眩脑肿。松节为驱风，止痛药；治历节风痛，风痹，脚弱
- 用量：普通一钱至三钱
- 禁忌：燥热症者忌

## 原文

> 味苦温。主治痈疽恶疮，头疡白秃，疥瘙风气，安五脏，除热。久服轻身延年。一名松膏，一名松肪。生山谷。
