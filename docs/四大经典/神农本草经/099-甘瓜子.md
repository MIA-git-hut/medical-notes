# 甘瓜子

> [!note] 本页为《神农本草经》上经（果菜部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：甘寒
- 主治：泻寒热，甘益脾，利二便，消水肿，止消渴，散热毒痈肿。子能补肝明目。现药物中所用之瓜子，皆冬瓜子也

## 原文

> 味甘平。主令人悦泽，好颜色，益气不饥。久服轻身耐老。
