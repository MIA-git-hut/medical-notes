# 薇衔

> [!note] 本页为《神农本草经》中经（草部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味苦性平无毒
- 主治：鹿衔草主治风湿痹，逐水。益筋节，疗痿躄，婴儿先天不足
- 用量：普通一二钱
- 禁忌：待孕之妇忌服，绝产

## 原文

> 味苦平。主治风湿痹，历节痛，惊痫吐舌，悸气贼风，鼠瘘痈肿。一名麋衔。生川泽。
