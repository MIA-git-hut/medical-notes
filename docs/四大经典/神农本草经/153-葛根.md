# 葛根

> [!note] 本页为《神农本草经》中经（草部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味甘，性平，无毒
- 主治：葛根为发汗解肌升阳散火要药，主消渴大热，伤寒中风，治头痛，泄泻，开胃气，解酒毒
- 用量：普通二钱至六钱
- 禁忌：多用反伤胃气，升散太过也，丹溪曰已见红密点，不可服葛根升麻，恐表虚反增斑烂

## 原文

> 味甘平。主治消渴，身大热，呕吐，诸痹，起阴气，解诸毒。葛谷，主下利十岁以上。一名鸡齐根。生川谷。
