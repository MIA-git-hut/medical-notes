# 龙眼

> [!note] 本页为《神农本草经》中经（木部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味甘，性平，无毒
- 主治：龙眼为滋养要药，主益脾长肌，养心安神，治血虚怔忡劳神健忘
- 用量：普通二至三钱
- 禁忌：甘能作胀，凡中满气膈之证均忌

## 原文

> 味甘平。主治五脏邪气，安志，厌食。久服强魂，聪明，轻身不老，通神明。生山谷。
