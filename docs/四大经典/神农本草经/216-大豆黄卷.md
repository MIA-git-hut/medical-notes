# 大豆黄卷

> [!note] 本页为《神农本草经》中经（米谷部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味甘，性平，无毒
- 主治：大豆黄卷为清热开胃，推陈去积要药，主行水去湿，胃气结积，治湿痹筋挛膝痛
- 用量：普通钱半至三钱
- 禁忌：恶海藻龙胆

## 原文

> 味甘平无毒。主治湿痹筋挛膝痛。生大豆，涂痈肿。煮汁饮，杀鬼毒，止痛。赤小豆，主下水，排痈肿脓血。生平泽。
