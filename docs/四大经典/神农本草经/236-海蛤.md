# 海蛤

> [!note] 本页为《神农本草经》中经（虫兽部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味苦咸．性平，无毒
- 主治：海蛤粉为软坚润下要药，主老痰，热痰，痰气喘咳，消瘿核，散肿毒，止呕逆，利小便，治妇人血病
- 用量：普通一至二钱
- 禁忌：畏甘遂芫花，虽善消痰积血块，然脾胃虚寒者宜少用

## 原文

> 味苦平。主治咳逆上气，喘息烦满，胸痛寒热。一名魁蛤。生池泽。
