# 蜂子

> [!note] 本页为《神农本草经》上经（虫兽部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味甘，性平，无毒
- 主治：蜂蜜为润脏腑要药，主益气补中，滋养脾胃，调和营卫，治五脏不足，肠胃燥结，肌肉疼痛，除心烦，疗肠澼，作榳入谷道，导便秘。蜂蜡为止血，安胎，补益药，治孕妇胎动下血有殊效，又为硬膏基础剂。蜜蜂子为补虚，解毒药，治麻风病及肠寄生虫结聚腹痛，滇越等地常以油炸佐膳
- 用量：可做食品，无定量
- 禁忌：无

## 原文

> 味甘平。主治风头，除蛊毒，补虚羸，伤中。久服令人光泽，好颜色，不老。大黄蜂子，主治心腹胀满痛，轻身益气。土蜂子，主治痈肿。一名蜚零。生山谷。
