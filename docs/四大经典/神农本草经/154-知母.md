# 知母

> [!note] 本页为《神农本草经》中经（草部中品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味苦，性寒，无毒
- 主治：知母为清凉解热要药，功能泻肺火，清胃火，下水消肿，利二便
- 用量：普通钱半至三钱
- 禁忌：能滑肠，泄泻者忌，阳痿及易举易痿，脾弱饮食不化，胃虚不思食，均忌，勿犯铁器，得黄相及酒良

## 原文

> 味苦寒无毒。主治消渴热中，除邪气，肢体浮肿，下水，补不足，益气。一名母蚳、连母、野蓼、地参、水参、水浚、货母。生川谷。

## 倪海厦《人纪》解说

> 以下要点摘编自倪海厦《人纪·神农本草经》讲座中「知母」一节，属其个人讲解风格，供对照学习。

**讲义所据原文**（含后世附注，与辑本文字互有出入）

> 味苦，寒，无毒。治消渴，热中，除邪气。肢体浮肿。下水，补不足。益气。一名蚳母。一名连母。一名野蓼，一名地参。一名水参。一名水浚。一名货母。一名蝭母

- 第171，知母，经方里面使用的非常多，大家看，知母长成这个这个样子，你们传阅一下，这就是知母，这个知母呢，它本身具有苦味，寒凉的药，治消渴
- 伤寒论里面有，我们有白虎汤，白虎汤呢，就是石膏还有配上知母，知母本身它的药性呢，是味道很苦，性寒，它是清凉解热的药
- 你看那个知母长的黄白相间的，黄黄白白的，就知道嘛，脾肺，脾肺之间的药，它主要的功能能泻肺火，清胃火，因为是这个苦味嘛，苦味主泻，所以它能把胃火清掉，所以我们白虎汤里面会用到知母，诸位记得哦，如果你这样子看，老师，你光看那个胃火，你不太容易了解，你说，老师，我怎么知道这个胃火很大？很简单啦，"你胃口好不好"？"超级好啊，吃，我从早可以吃到晚"

- 唐容川：知母叶至难死。拔之犹生，即知其得水气多，故能清气分之热
