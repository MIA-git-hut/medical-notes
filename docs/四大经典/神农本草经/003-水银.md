# 水银

> [!note] 本页为《神农本草经》上经（玉石部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」与「解说」均摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味辛，性寒，有毒
- 主治：水银为杀虫要药，主治杨梅疮毒，及皮肤诸病，润肠下死胎
- 用量：普通多配合丸散方用，内服约数分，外用无定量
- 禁忌：水银性沉，与金银诸物同，吞服金银水银者，皆足以致命，饵服者须慎之

## 原文

> 味辛寒。主治疥瘙痂疡百秃，杀皮肤中虫虱，堕胎，除热。杀金银铜锡毒，熔化还复为丹。久服神仙不死。生平土。
