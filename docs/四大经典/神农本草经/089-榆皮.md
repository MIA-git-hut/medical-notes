# 榆皮

> [!note] 本页为《神农本草经》上经（木部上品）药物，原文据通行辑本文字转写简体；「学习要点」的「性味」「主治」「用量」「禁忌」摘自倪海厦《人纪·神农本草经》讲座讲义，属其个人讲解风格，供对照学习。

## 学习要点

- 性味：味甘性平，滑利，无毒
- 主治：榆白皮为泄滞去着，利水消肿要药，主大小便不通，利五淋，渗湿热，治肠胃邪热，水肿，痈肿，外敷疗癣湿，头疮
- 用量：普通二三钱
- 禁忌：此能利窍渗湿热，去有形之积，气盛而壅者宜之，若胃寒而虚者，久服恐泄真气

## 原文

> 味甘平。主治大小便不通，利水道，除邪气。久服轻身不饥。其实尤良。一名零榆。生山谷。
