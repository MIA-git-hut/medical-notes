# 四大经典

> [!note] 本部分为**目录级框架**：篇目结构完整呈现，原文与选读内容按需逐步补充。

中医四大经典，是学习中医的根基：

| 经典 | 成书 | 核心内容 |
| --- | --- | --- |
| [黄帝内经](/四大经典/黄帝内经/) | 战国至秦汉 | 素问、灵枢各 81 篇；中医理论体系的奠基之作 |
| [伤寒论](/四大经典/伤寒论/) | 约东汉 · 张仲景 | 宋本 10 卷 22 篇；中十篇 398 条，为六经辨证核心 |
| [金匮要略](/四大经典/金匮要略/) | 约东汉 · 张仲景 | 25 篇；以内科杂病为主的杂病证治 |
| [神农本草经](/四大经典/神农本草经/) | 约东汉 | 载药 365 味，分上、中、下三品；现存最早的药学专著 |

## 定位说明

- 只做知识整理与检索，**不做诊疗建议**
- 内容尽力标注篇目出处，可溯源古籍原文
- 各篇目暂为框架，原文与选读逐步补充

> [!tip] 另有「四大经典含《温病条辨》」一说
> 在一些教学体系中，四大经典指《黄帝内经》《伤寒论》《金匮要略》《温病条辨》（不含《神农本草经》）。本站在中药方向以《神农本草经》为准；《温病条辨》框架视整理进度后续补充。
